# 肾猫知识库与营养评估

## 用途路由

收到问题时先判断属于哪一类，只读取对应文件，不要一次性把 references 全读进来。

## 核心规则

### 1. 资料优先级与核验

本技能有两套数据源，**冲突时必须显式标出**，不许静默选一个：

- **本地资料**：`references/` 与 `data/` 中标记 `[你的资料]` 的内容，来自用户自己收集的肾猫资料，优先采用。
- **权威基准**：标记 `[IRIS 2023]` / `[AAFP]` / `[文献]` 的内容，来自公开指南。

输出时：
- 两者一致 → 正常陈述，不必重复标注来源。
- 两者冲突 → 必须写成 `⚠️ 你的资料写 X，IRIS 2023 指南为 Y，建议复核`，并说明哪个更可能是笔误/版本差异/单位差异。
- 单位不同（mg/dL vs mmol/L，as-fed vs DM）造成的"冲突"要在换算后判断，不要直接报警。

### 2. 医疗边界（不可突破）

- 这是**资料整理与科普工具，不是诊断工具**。任何具体病例都必须加一句"以主治兽医的判断为准"。
- 不允许给出具体的处方药剂量作为最终建议——可以列出 `references/04` 中的常规剂量范围供参考，但必须标注"由兽医确定"。
- 遇到这些情况，直接建议立刻就医，不要尝试自己解答：
  - 猫超过 24 小时完全不进食
  - 呕吐/腹泻持续超过 1 天
  - 突发失明（可能是视网膜脱离/高血压危象）
  - 抽搐、昏迷、无法站立
  - 无尿超过 24 小时（需排除尿路阻塞，公猫尤其紧急）

### 3. 数值处理约定

- 所有百分比用 `0.00%` 格式，缺失填 `-`。
- 猫粮营养值必须**同时标注 as-fed 与干物质（DM）**，换算：`DM% = as-fed% ÷ (1 - 水分%)`。
- 单位换算常量见 `references/02` 的换算表，不要凭记忆算。
- 热量单位统一用 kcal/kg 与 kcal/100g，需要时用改进 Atwater 公式估算（见 `scripts/renal_eval.py`）。

### scripts/

- `renal_eval.py` — 猫粮营养评估：输入营养数据，输出干物质换算、磷/蛋白/钠评级、IRIS 各期适用性、热量估算
- `iris_stage.py` — 输入肌酐/SDMA/UPC/血压，输出 IRIS 分期与亚分期
- `calcitriol.py` — 骨化三醇分药计量：输入体重，输出单次 ng 数与每粒分几份

用法：
```bash
python scripts/renal_eval.py "蛋白 32% 脂肪 18% 纤维 2% 灰分 6% 钙 0.9% 磷 0.7% 水分 8%"
python scripts/iris_stage.py --creatinine 2.4 --sdma 22 --upc 0.3 --sbp 165
python scripts/calcitriol.py --weight 5.48
```

## 收到新资料时执行

1. 判断归属（01-08 哪个文件 / 哪个 CSV）
2. 追加内容，来源标记为 `[你的资料]`
3. 与权威基准交叉核验，冲突处写进该文件顶部的「⚠️ 待复核清单」
4. 更新 `references/` 索引表的状态列与本「已导入资料」表
5. **重新生成 `AUDIT-跨资料核验与待复核汇总.md`**，并做一次跨资料比对：新资料的定位是否与已有资料冲突（例：益生菌在用药清单里是"延缓进程"，在 2026 综述里是"辅助/研究性"）
6. **同步 `assets/deliverables/` 里的 HTML / XLSX 交付物** —— 同一批数据往往同时存在于 `references/` 与交付物中，只改一处就会出现「一个技能两套口径」（2026-10-06 实例：`11` 改了赛瑞宁剂量，但 HTML/XLSX 仍是旧值）。做法：
   - 先 `grep -rl "<关键词>" <技能根>` 列出所有提及该数据的文件，逐个判断是否需要改（索引类文件通常不必）
   - 对 HTML/XLSX 用**断言式脚本**批量替换：先干跑并统计每处 `old` 的命中数，与期望不符就中止不写；通过后再 `--apply`
   - **优先在单元格 / 文本片段内替换**，不动列宽、冻结窗格、`wrap_text`、合并单元格等样式
   - 改前先 `cp` 到备份目录（如 `_skill_bak_YYYYMMDD/`）
   - 注意 HTML 的 `data-txt` 搜索属性与正文常**大小写不同**（正文 `CKD`／`data-txt` `ckd`），需分别写两条替换规则；文本里也可能带 `\n`，匹配片段要按原始换行构造
7. **口径差异集中标注，不静默改写** —— 社区清单、IRIS 与指南的口径常有实质差异（如替米沙坦降压 2 / 蛋白尿 1 vs 指南单药 2、联用 ≤1）。此类差异**都要有来源，不是错**：应并列呈现并注明出处表号，而不是用一方覆盖另一方。
