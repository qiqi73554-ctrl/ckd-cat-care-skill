## 评判标准（评估任何一款粮的尺子）

拿到一款粮的数据，按这个顺序过一遍：

| 步骤 | 判据 | 结论 |
|---|---|---|
| 1. 换算干物质 | 所有 as-fed 值 ÷ (1−水分%) | 否则干湿粮无法比较 |
| 2. 看磷 | DM 磷 ≤ 0.6%？≤ 0.5% 更优 | 超标直接判不适合 |
| 3. 看 Ca:P | ≥ 1.0？ | 低于 1.0 是减分项 |
| 4. 看磷形态 | 配料表有无磷酸钠/钾等无机盐 | 有 → 减分（吸收率高） |
| 5. 看蛋白与分期 | Stage 1–2 不必限蛋白；3–4 适度限 | 结合分期判断 |
| 6. 看水分 | 湿粮 > 干粮 | 肾猫普遍优先湿粮 |
| 7. 看钾 | 有低钾史 → 选高钾款 | 1.5–3.5 g/1000kcal 区间内选 |
| 8. 算热量 | 不足则换粮无意义 | 见 `scripts/renal_eval.py` |

**一句话判据**：干物质磷 ≤ 0.5% + Ca:P ≥ 1.0 + 无无机磷盐 + 湿粮，四项全中才谈得上"肾猫友好"。

### 已知参照

- 处方肾粮：磷 **0.3–0.5% DM**，比普通成猫粮低 40–60% `[文献]`
- 普通成猫粮常见磷：0.8–1.5% DM（**多数不适合**肾猫）
- 主食冻干/生骨肉：因含骨粉，磷往往偏高，**Ca:P 需重点核对**
- AAFCO 成猫磷最低要求 0.5% DM —— 注意这是"最低"，与健康上限无关

## 湿粮优先原则

- 干粮为主的猫总摄水量比湿粮猫少约 50% `[WSAVA 2011]`
- 罐头含水 70–80%
- 优先级：**主食湿粮 > 干粮泡水/加水 > 纯干粮**
- 纯干粮方案必须配合饮水机、多点水碗、湿零食补水

## 换粮方法

- 周期：**4–6 周**（也有 7–14 天的快速方案，视猫接受度）
- 起始：新粮 10–15%（或 25%）混入旧粮，每 4–7 天递增
- 加温至 **38–39 °C**（接近体温）可提升适口性
- 可加低钠肉汤
- **硬红线**：拒食超过 3 天不要强推；猫完全绝食 3–5 天有肝脂沉积风险，比肾病本身更危险
- Stage 4：进食优先于处方，宁可吃普通湿粮也不要不吃

## 磷结合剂与食物的配合

- 只有当单纯限磷饮食**无法达标**时才加（常见 Stage 3–4）
- 在维持日粮或老年粮上加磷结合剂效果**不如直接喂肾粮**
- 详见 `04-用药与护理.md`
