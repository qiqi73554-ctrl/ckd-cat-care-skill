## 复查频率 `[IRIS 2023]`

| 分期 | 复查间隔 |
|---|---|
| Stage 1–2 | 每 3–6 个月 |
| Stage 3 | 每 2–3 个月 |
| Stage 4 | 每 1–2 个月，或按临床需要 |

- 初次发现肾功能指标异常但无 CKD 证据：2–3 个月后复查；若肌酐上升则每 3 个月，稳定则每 6 个月
- **趋势远比单点重要**——任何指标都要连成曲线看

## 核心指标参考

### 肌酐

| 项目 | 值 |
|---|---|
| 猫常见参考区间 | 约 0.8 – 2.0 mg/dL（70–180 μmol/L），**各实验室不同，以本院为准** |
| 影响因素 | 肌肉量（恶病质猫假性偏低）、水合状态、饮食 |
| 判读 | 必须结合 USG、体检、水合状态，排除肾前性/肾后性 |

### SDMA

| 项目 | 值 |
|---|---|
| 参考区间 | < 14 μg/dL |
| 提示肾功能下降 | 持续 > 14 |
| 不受肌肉量影响 | 是 |
| GFR 下降检出阈值 | 约 25%（肌酐约 75%） |

### 血磷

| 分期 | 目标 mg/dL | 目标 mmol/L |
|---|---|---|
| Stage 1–2 | 2.7 – 4.6 | 0.87 – 1.49 |
| Stage 3 | < 5.0 | < 1.62 |
| Stage 4 | < 6.0 | < 1.94 |
| 绝对干预线（任何期） | > 6.0 | > 1.9 |
| 理想值 | ≤ 4.0 | ≤ 1.3 |

### 尿比重 USG

| 项目 | 值 |
|---|---|
| 猫参考范围 | 1.008 – 1.035+ |
| CKD 典型 | 浓缩能力下降，USG 常落在 1.008–1.020 |
| 注意 | **部分肾性氮质血症的猫仍能产生高比重尿**，不能单靠 USG 排除 CKD |

### UPC

| UPC | 判定 |
|---|---|
| < 0.2 | 非蛋白尿 |
| 0.2 – 0.4 | 临界 |
| > 0.4 | 蛋白尿（猫的治疗阈值） |

需 3 次采样、间隔 ≥ 2 周。血尿/感染/炎症致假阳性。

### 血压

| 收缩压 mmHg | 分级 |
|---|---|
| < 140 | 正常 |
| 140 – 159 | 高血压前期 |
| 160 – 179 | 高血压 |
| ≥ 180 | 重度 |

### 碳酸氢盐

目标 16 – 25 mmol/L（稳定、水合良好）

### 血钾

- 低钾：20–30% CKD 猫，导致肌无力（颈部腹屈）、多尿、便秘
- 肾粮也可能致高钾，需按个体选

### 红细胞压积 HCT / PCV

- 非再生性贫血随分期进展常见
- 肾性贫血为正常细胞正常色素性

### FGF-23 `[IRIS 2023]`

| 情境 | 阈值 | 行动 |
|---|---|---|
| Stage 1–2，血磷在目标内 | > 400 pg/ml | 开始限磷（排除高钙血症、贫血、炎症） |
| Stage 4 | > 700 pg/ml | 加强限磷（同上排除条件） |

## 每次复查建议项目组合

**基础组合**：体重 + 肌肉状况评分、BCS、SDMA、肌酐、BUN、血磷、血钙、血钾、总钙、PCV、USG、UPC、血压

**进阶（按分期与需要）**：FGF-23、PTH、碳酸氢盐/血气、离子钙、尿培养、影像学

## 判读原则

1. **看趋势**：单次升高不如连续 3 次上升有意义
2. **看水合**：脱水会让所有肾指标假性升高，先纠正再判读
3. **看分期一致性**：肌酐与 SDMA 不一致时考虑肌肉量，2–4 周复查，持续不一致取高分期
4. **分期不是预后**：IRIS 分期不反映进展速度，而进展速度往往才是最重要的预后因素
5. **Stage 1 单独靠血检难诊断**，需结合影像与尿检
