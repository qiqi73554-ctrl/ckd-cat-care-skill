## 分级图例
- **A** 指南/强推荐 ｜ **B** 常规用药（有临床共识）｜ **C** 辅助/经验（证据有限）｜ **⚠** 高危/需监测

## 四个用法要点
1. **先分期、再选药**：原表标注「建议使用分期」，1–2 期与 4 期用药重点完全不同。
2. **随餐/空腹决定有没有效**：磷结合剂必须餐中吃，硫糖铝必须空腹，搞反了等于白吃。
3. **叠加前先查间隔**：活性炭、磷结合剂、硫糖铝都会「吸附」其他药。
4. **黄色区块为整理者补充**（循证提示+风险提醒）。

## ① 按症状倒查（顺序=优先级）
| 现在的问题 | 先考虑这些 |
|---|---|
| 不吃/厌食 | 米氮平(透皮) ｜ 赛庚啶 ｜ 赛瑞宁(先排除恶心) ｜ 查口腔疼痛与尿毒症胃炎 |
| 呕吐/干呕/流口水 | 赛瑞宁 ｜ 奥美拉唑 ｜ 硫糖铝(空腹) ｜ 排查脱水/梗阻/胰腺炎/尿毒症 |
| 黑便/呕血/胃溃疡 | 硫糖铝(空腹 1h 前) ｜ 奥美拉唑 ｜ 急诊+查血压血磷 |
| 便秘/大便干硬 | 乳果糖 3ml 起 ｜ 拜耳 3350 ｜ 西沙比利/莫沙必利 ｜ 先补液体与饮水 |
| 口臭/口腔溃疡/口炎 | 口腔护理(碘甘油/康复新液/可鲁等) ｜ 同步降氮+镇痛 ｜ 排查牙结石/齿吸收 |
| 贫血(HCT 低/牙龈白) | 轻度：B12、叶酸、硫酸亚铁、补血肝精 ｜ 重度：富血力、兽用 VB/B12 注射 ｜ HCT<25%：DPO/EPO(需兽医) |
| 血磷高 | 碳酸镧(餐中) ｜ 维福瑞(餐中) ｜ 氢氧化铝(短期) ｜ 根本：低磷饮食 |
| 肌酐/BUN 高 | 先排查脱水与梗阻 ｜ 皮下补液 ｜ 益生菌/吸附剂(辅助) ｜ 别指望单靠补充剂降 |
| 高血压(>160) | 氨氯地平 1/8 片起 ｜ 目标**理想 <140、否则 <160** mmHg ｜ 查甲亢与眼底/心脏靶器官 |
| 蛋白尿(UPC 高) | 替米沙坦 2 mg/kg q24h ｜ 贝那普利 0.5–1.0 mg/kg(进阶) ｜ **替米沙坦与氨氯地平联用时，须从 ≤1 mg/kg 起** |
| 血钾低 | 葡钾片 ｜ 潘南金 ｜ 查饮食与补液配方 |
| 血钾高(≥6.5) | 急诊 ｜ 利倍卓(专科指导) ｜ 48h 复查血气 |
| 代谢性酸中毒 | 碳酸氢钠(按血气算量) ｜ 柠檬酸钾(低钾时) |
| 抽搐/癫痫 | 急性：左乙拉西坦(急诊) ｜ 长期：苯巴比妥 ｜ 查血压与尿毒症脑病 |
| 后肢无力 | 先查血钾 ｜ 兽用 VB/B12 注射 1 支/周 |
| 多囊肾 PKD | 灵芝孢子油 ｜ 百令/DHF(辅助) ｜ 重点：血压+感染监控 |

## ② 重点药物速记
- **A 级（强推荐）**：替米沙坦 2 mg/kg q24h(蛋白尿)、碳酸镧(降磷)、赛瑞宁/马罗匹坦 1 mg/kg q24h(止吐)、米氮平 2 mg/猫 q24h（高分期 q48h）(促食欲)、氨氯地平 0.125–0.25 mg/kg q24h(降压)、DPO 达贝泊汀(贫血)。
  > 上述剂量采 **iCatCare 2026 指南口径**（Table 4/6）。注意**赛瑞宁**：原社区清单写 2 mg/kg，指南为 1 mg/kg q24h，用猫请与兽医确认。
- **C 级（辅助/经验，证据有限）**：胺肾、贝前列素钠、百令、灵芝孢子油、DHF、各类益生菌/肠道透析(肾透/NOW/VISBIOME 等)、壳聚糖、尿毒清、活性炭类。
- **整理者删除/警示项**：奇亚籽（磷 800–900 mg/100g，反向操作）、3% 双氧水家庭涂口腔（灼伤黏膜）、EPO 尽量换 DPO（抗 EPO 抗体→纯红再障 PRCA）、铁剂先确缺铁、骨化三醇必查离子钙、活性炭隔 2h 且加重便秘。

## ③ 服药时机与冲突间隔（关键）
| 药物 | 最佳时机 | 必须错开/注意 |
|---|---|---|
| 磷结合剂(碳酸镧/维福瑞/氢氧化铝) | 餐中或餐后立刻 | 与铁剂、抗生素、抑酸剂(奥美拉唑)、ACEI、激素 隔 2–3h |
| 活性炭类 | 空腹/睡前 | 与一切食物药物 间隔 2h |
| 硫糖铝 | 餐前空腹 1h | 与其他所有药 间隔 ≥2h |
| 奥美拉唑 | 餐前空腹 | 与氯吡格雷禁忌合用；与硫糖铝/磷结合剂错开 |
| 骨化三醇 | 空腹(原表：周三晚+周日早) | 禁与含钙磷结合剂、含镁抗酸剂、巴比妥类、皮质类固醇、噻嗪类利尿剂同用 |
| 益生菌 | 随餐/拌饭 | 与抗生素隔 2h；AZODYL/AZOVAST 需空腹 |
| VB/B12 注射 | 皮下 | 不要混进补液袋（会被稀释） |
| DPO/EPO | 皮下，固定日期 | 避免与 ACEI 随意叠加 |
| 灵芝孢子油/百令 | 口服 | 与抗凝药隔 2h；其余药隔 1h |
| 米氮平 | 抹耳廓内侧(透皮) | 戴手套避免自吸；24h 内不重复；**CKD 高分期者因肾清除率降低可 q48h** |

> 建议画一张时间表贴冰箱：空腹档(骨化三醇/硫糖铝/奥美拉唑/AZODYL)、随餐档(磷结合剂/益生菌/铁剂)、间隔档(活性炭、灵芝孢子油)。任何两种不确定→默认隔 2h 最安全。

## ④ 复查节奏
| 药物 | 什么时候复查 | 看什么 |
|---|---|---|
| 替米沙坦/贝那普利 | 社区版：开始 2 周→正常再 2 周→正常则 1 月后<br>**指南版：1–2 周 → 4 周 → 每 3 个月** | 血压+血钾+肌酐+UPC。**肌酐升高 >25–30% 可能需调整剂量**（iCatCare 2026 Table 5） |
| 贝前列素钠 | 吃 2 周 | 肌酐/BUN/血压（可能短期升） |
| 骨化三醇/丰兹欧 | 用前查离子钙；用后 1–2 周 | 离子钙/总钙/磷(钙磷乘积) |
| 贫血治疗(铁/B12/DPO/EPO) | 2–3 周；DPO 调整期每周 | HCT/RBC/HGB/网织 |
| 磷结合剂 | 调量后 4 周 | 血磷(达分期目标) |
| 利倍卓(高钾) | 用药后 48h | 血钾/钠/水肿便秘 |
| 氨氯地平 | 开始/调量后 1–2 周 | 收缩压（**目标理想 <140，否则 <160**） |

## ⑤ 风险红榜（整理者补充）
- ⚠ 奇亚籽「降钙」：磷高(800–900 mg/100g)，帮倒忙。
- ⚠ 3% 双氧水涂口腔：灼伤黏膜、误吞致呕吐/食道炎。
- ⚠ 长期含铝磷结合剂：铝蓄积→神经症状/小细胞性贫血，尽量短期低剂量。
- ⚠ 盲目补铁：不查铁状态长期口服→便秘、干扰吸收、氧化损伤。
- ⚠ 骨化三醇不看离子钙：高钙加速肾与软组织钙化（越补越坏）。
- ⚠ 活性炭当主力降氮：非选择性吸附，吸走所有同服药+加重便秘脱水。
- ⚠ EPO 替代 DPO：人用 EPO 免疫原性高，可能诱发 PRCA。
- ⚠ 自行叠加降压药：替米沙坦+贝那普利放大高钾与肾灌注下降；**替米沙坦与氨氯地平联用时必须从 ≤1 mg/kg q24h 起**（防低血压），联合治疗须密切监测血压。
- ⚠ 脱水或 CKD 不稳定时上 RAAS 抑制剂（ARB/ACEI）：指南明确**仅用于未脱水且病情稳定的猫**，否则可能加重肾灌注不足。

## ⑥ 按 IRIS 分期的用药阶梯
- **1–2 期**：血压与蛋白尿是主线——UPC>0.4 考虑替米沙坦 2 mg/kg q24h；血压>160 上氨氯地平 0.125–0.25 mg/kg q24h（**目标理想 <140、否则 <160**）；低磷饮食起步；补充剂(胺肾/鱼油/益生菌)可选。
- **3 期**：加降磷(碳酸镧/维福瑞随餐)；监测贫血与血钾；BUN 高考虑益生菌/吸附剂；开始考虑皮下补液。
- **4 期**：通常需规律皮下补液；止吐(赛瑞宁)+护胃(奥美拉唑/硫糖铝)+促食欲(米氮平)组合；严重贫血评估 DPO；考虑喂食管。

> 分期依据 IRIS 2026（肌酐/SDMA + UPC + 血压）。详细剂量与喂药技巧见完整 HTML/XLSX 资产与《照护手册》第 6 章。
