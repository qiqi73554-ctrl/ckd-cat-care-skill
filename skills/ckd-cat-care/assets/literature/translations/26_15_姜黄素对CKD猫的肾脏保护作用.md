姜黄素对慢性肾病（CKD）猫的肾脏保护作用

Murat İlgün 1, Mustafa Sinan Aktaş 2,✉ 猫的慢性肾病（CKD）以氧化应激、炎症和细胞凋亡为特征。姜黄素在实验模型中显示出肾脏保护作用，但在慢性肾病（CKD）猫的临床证据仍然有限。

## 假设/目标

评估口服(PO)姜黄素补充剂（每只猫80毫克/天）在标准治疗下，是否有利于调节患有国际肾脏兴趣协会（IRIS）3期慢性肾病（CKD）猫的肾功能、氧化、炎症和凋亡生物标志物。研究对象为16只IRIS 3期CKD的宠物猫。前瞻性、随机试验。猫被分配到单独药物治疗组（MT；n = 8）或药物治疗加姜黄素组（MT+C；n = 8）。姜黄素以口服方式，每只猫每天80毫克，分2次给药，持续60天。基线肾功能生物标志物在两组之间无显著差异。主要结果血清对称二甲基精氨酸（SDMA）浓度在第30、45和60天，MT+C组显著低于MT组（P < .01）。尿蛋白-肌酐比随时间在MT+C组下降，在后期时间点低于MT组。MT+C组总抗氧化状态增加，而总氧化状态下降，第45天两组在总氧化状态上存在显著差异。

核因子κB和半胱天冬酶-3的检测结果也与姜黄素治疗的猫体内炎症和凋亡活性降低一致。

## 结论与临床重要性

薑黄素补充与SDMA改善以及猫IRIS 3期慢性肾脏疾病（CKD）机制性生物标志物的有利变化相关。关键词：凋亡、猫、慢性肾病（CKD）、姜黄素、氧化应激、SDMA 慢性肾脏疾病（CKD）是一种进展性且不可逆的疾病，常见于老龄猫，其特征为肾小球硬化、肾小管萎缩、间质纤维化和慢性炎症。 国际肾脏兴趣协会（IRIS）根据血清肌酐和对称二甲基精氨酸（SDMA）浓度将CKD分为4期，其中第1期代表早期疾病，第4期反映严重氮质血症和晚期肾功能障碍。尽管兽医肾脏学取得了进展，当前的治疗仍主要是姑息性的，旨在减缓疾病进展并缓解临床症状。然而，这些方法并未直接针对肾损伤的分子机制。猫CKD的诊断基于临床症状、实验室检查结果和诊断成像。

持续性氮质血症、尿液浓缩不足（尿比重（USG） [USG] < 1.035）以及 SDMA 浓度升高是早期检测和分期的关键指标。根据 IRIS 指南，蛋白尿和系统性血压也用于亚分期。虽然传统上血清肌酐浓度用于评估肾功能，但 SDMA 在某些猫中可能更早提示肾小球滤过率（GFR）下降。治疗策略包括肾脏专用饮食、皮下液体、抗高血压药物如氨氯地平，以及血管紧张素受体拮抗剂如替米沙坦。贫血和胃肠道症状的管理进一步改善生活质量。氧化应激、炎症和细胞凋亡是慢性肾病（CKD）发病机制的关键因素。病变肾组织产生的活性氧（ROS）导致脂质过氧化、DNA 损伤和蛋白质氧化，引发促炎性细胞因子和转录因子如核因子κB（NF-κB）的激活。

这些级联反应导致肾小管上皮细胞死亡和肾单位逐渐丧失，这在啮齿动物的实验性慢性肾病（CKD）模型以及患有慢性肾病（CKD）的人类中已有所证明。12 姜黄素是一种来源于姜黄（Curcuma longa）的多酚化合物，在啮齿动物的肾损伤模型中，包括缺血–再灌注、糖尿病肾病和毒素诱导的肾病，显示出抗氧化、抗炎和抗凋亡的特性。13–15 这些作用涉及氧化途径的调节、抗氧化酶的上调，包括超氧化物歧化酶（SOD）、过氧化氢酶（CAT）和谷胱甘肽过氧化物酶（GPx）；抑制NF-κB及肿瘤坏死因子-α（TNF-α）、白细胞介素-6（IL-6）和白细胞介素-1β（IL-1β）等细胞因子；以及通过Caspase-3和B细胞淋巴瘤2（Bcl-2）调节凋亡。16–18 尽管具有这些令人鼓舞的特性，但姜黄素在患有慢性肾病（CKD）的猫中的临床疗效仍未经过验证。

通过新型制剂提高生物利用度增强了其临床应用潜力。19,20 我们假设每日口服给予姜黄素（每只猫每天80毫克），结合常规治疗，可以通过调节氧化应激、炎症和凋亡，对患有3期慢性肾病（CKD）的猫产生肾脏保护作用。

## 材料与方法

共有二十四只由客户拥有的猫被纳入研究：8只临床健康的对照猫和16只处于IRIS 3期慢性肾病（CKD）的猫。慢性肾病（CKD）的诊断依据为持续性氮质血症、尿比重（USG） < 1.035、相符的临床症状以及腹部超声检查。分期基于稳定后血清肌酐浓度（2.9-5.0 mg/dL）；SDMA浓度（≥26 μg/dL）支持慢性肾功能障碍，但不用于分期。患有肾前性氮质血症、伴随系统性疾病或近期使用抗氧化剂或抗炎补充剂的猫被排除在外。患有CKD的猫随机分为单纯药物治疗组（MT; n = 8）和药物治疗加姜黄素组（MT + C; n = 8）。健康对照猫仅在基线进行样品采集以进行疾病特征描述，不用于评估治疗效果。主要终点是血清SDMA浓度的纵向变化。次要终点包括尿蛋白与肌酐比值（UPC）、总抗氧化状态（TAS）、总氧化状态（TOS）、NF-κB和caspase-3；其他变量为探索性研究指标。

两组慢性肾脏病（CKD）猫都接受了IRIS指导的医疗管理，包括肾脏饮食、在适当情况下的液体治疗、高血压或蛋白尿的替米沙坦、持续高磷血症的碳酸镧、血钙过高的膳食钙调节、钾补充、在需要时使用马洛匹坦或米氮平，以及用于贫血的达贝泊汀和铁。MT C组猫 additionally 额外接受口服姜黄素（Solgar全谱姜黄素），剂量为每猫每天80毫克，分2次随食服用，持续60天。MT组未使用安慰剂。整个研究期间，实验室人员对分组分配保持盲法。在治疗前的第0天以及第15、30、45和60天，从CKD猫收集血液和尿液；对照组在基线时采样一次。额外的方法学细节，包括治疗方案、采样程序以及测定分析特性，见补充方法S1。

## 临床结果

在年龄、性别、绝育状态或体重方面，MT组与MT C组之间未发现显著差异（P = .73、P = .68、P = .71 和 P = .62）。在患有慢性肾病（CKD）的猫中（n = 16），年龄范围为7至15岁，平均±标准差为11.2 ± 3.4岁。患有CKD的猫群主要为家短毛猫（69%，11/16），其次为英国短毛猫（6%，1/16）、苏格兰折耳猫（6%，1/16）、波斯猫（6%，1/16）、暹罗猫（6%，1/16）和安卡拉猫（6%，1/16）。总体来看，62%为雄性（10/16；均已绝育），38%为雌性（6/16；均已绝育）。CKD猫最常见的临床症状为体重下降和厌食（94%，15/16）、多尿和多饮（88%，14/16）、脱水（75%，12/16）以及嗜睡（69%，11/16）。IRIS分期是基于基线血清肌酐浓度进行的，同时辅以SDMA作为辅助生物标志物评估。MT组有一只猫在第44天死亡，MT C组有一只猫在第31天死亡；两起死亡都归因于CKD的进展，而非研究程序或干预措施。

健康对照猫（n = 8）年龄在6到13岁之间（9.8 ± 2.6岁）。对照组包括5只雄性（均已绝育）和3只雌性（均已绝育）。品种包括家养短毛猫（6/8）、英短（1/8）和苏格兰折耳猫（1/8）。体重为4.6 ± 0.8公斤。所有对照猫均为临床健康并具有理想的体况评分。所有CKD猫均接受肾脏饮食和碳酸镧作为标准化基线治疗（MT: 8/8; MT C: 8/8）。两组中所有高血压和蛋白尿猫均服用特米沙坦（高血压：MT: 8/8; MT C: 8/8；蛋白尿：MT: 8/8; MT C: 8/8）。6只贫血猫需要达尔贝泊汀治疗（MT: 3/8; MT C: 3/8），所有猫同时也接受口服铁补充剂。3只猫补充了钾（MT: 2/8; MT C: 1/8）。12只猫使用米氮平刺激食欲（MT: 6/8; MT C: 6/8），13只猫因呕吐使用马洛匹坦柠檬酸盐治疗（MT: 7/8; MT C: 6/8）。

总体而言，各组的基线并发治疗分布相当，并且在研究期间未引入新的药物。慢性肾病（CKD）猫的超声检查结果显示出一致的慢性肾脏变化模式，包括皮质回声增强（100%，16/16）、皮髓质分界不清（69%，11/16）、肾脏边缘不规则（50%，8/16）以及肾脏体积减少（13%，2/16）。

## 收缩压（SBP）结果

在基线时，两组治疗组的收缩压（SBP）均升高。在大多数时间点，MT 组和 MT C 组之间的收缩压（SBP）差异不显著（P > .05）。在 MT C 组，与基线相比，第 60 天的收缩压（SBP）显著下降（P < .05）。第 60 天时，MT C 组的收缩压（SBP）明显低于 MT 组（P < .05）。我们评估了姜黄素补充对患有慢性肾病（CKD）的猫的肾脏保护作用，重点关注其对肾功能生物标志物、氧化应激、炎症和细胞凋亡的影响。研究结果强调了姜黄素作为慢性肾病（CKD）猫辅助治疗的潜在疗效，表明其能够改善 SDMA 浓度、调节氧化平衡、抑制 NFκB 介导的炎症，并通过调控半胱天冬酶-3 下降细胞凋亡活性。

肾功能生物标志物，如血清肌酐和SDMA浓度，在基线时MT组和MT C组之间没有显著差异，这确认了干预前各治疗组是可比的。在整个研究过程中，两组的血清肌酐浓度保持稳定，这与3期CKD中肾单位丢失通常已经比较严重的预期一致。相比之下，从第30天起，MT C组的SDMA浓度显著低于MT组。对称二甲基精氨酸（SDMA）通常被视为猫GFR变化的敏感指标。然而，最近的比较研究表明，在氮质血症CKD队列中，SDMA在与测量GFR直接相关时并不总是优于肌酐。这些发现表明，SDMA应在更广泛的生理背景下进行解释，而不应作为GFR的唯一指标。

有报道称，姜黄素可以通过增强一氧化氮的生物利用率、改善内皮功能以及支持皮质微血管灌注来调节肾血管和微循环功能。22,23 然而，考虑到SDMA和肌酐主要通过肾小球滤过率(GFR)排除，且肾小管处理极少，肾血流动力学的变化预计会影响这两种生物标志物。因此，在 MT C 组中观察到SDMA下降而血清肌酐浓度没有同步变化，不应被解读为姜黄素对肾小球或肾小管有选择性作用的证据。相反，这种模式很可能反映了在慢性肾病（CKD）猫的短期观察中，生物标志物反应性的差异。要阐明这些关系，需要未来的研究结合对GFR的直接测量。

磷和钙调节失调是慢性肾脏病常见并发症，主要由肾脏排泄受损和继发性副甲状腺功能亢进引起。24,25 在我们的研究中，两组慢性肾脏病患者在观察期内血清磷浓度持续上升，这与报告一致，即晚期慢性肾脏病患者尽管采用多模式医疗管理，高磷血症仍常持续进展。26 尽管所有猫使用鑭，血清磷浓度持续上升反映了IRIS第3-4期疾病的既有病理生理机制。在此阶段，功能性肾单位质量下降、23号成纤维细胞生长因子（FGF-23）分泌增加、磷酸排泄受损及继发性副甲状腺功能亢进限制了饮食限制和磷结合剂的疗效。27 因此，本研究中血清磷浓度未下降反映的是晚期慢性肾病（CKD）的代谢抵抗性，而非治疗方案或姜黄素给药差异。

钙稳态呈现出更稳定的模式。尽管在后期时间点观察到轻微波动，但各组之间未出现显著差异，且姜黄素补充未导致血清钙浓度的可测量变化。MT+C 组的相对稳定的钙谱与目前关于慢性肾病（CKD）中氧化应激、炎症和矿物质代谢相互依存的理解一致。实验研究表明，姜黄素可以通过影响氧化还原平衡、改变跨膜钙通量以及支持细胞内稳态信号通路来调节钙调控机制。这些机制为解释我们研究中观察到的钙模式提供了连贯的生物学依据。

从第30天起，MT C组的尿蛋白-肌酐比值显著下降，并在第60天仍保持较低水平，而MT组的UPC保持不变。持续性蛋白尿是慢性肾病（CKD）进展中公认的预后指标。MT C组观察到的UPC下降趋势与调节炎症和氧化还原相关通路能够影响肾小球通透性动态的概念一致。实验研究表明，姜黄素能够与控制肾小球功能的关键分子网络相互作用，包括转化生长因子-β（TGF-β）、NF-κB和应对氧化应激的信号级联通路。这些通路对于维持内皮稳态、细胞外基质组织以及肾小球滤过屏障的选择性通透性至关重要。因此，MT C组观察到的UPC变化轨迹与实验肾脏学中描述的机制模式一致，并反映了在姜黄素介导的肾小球调节的更广泛框架内具有生物学合理性的反应。

姜黄素在慢性肾病（CKD）中的作用不仅限于抗炎活性，还包括与氧化途径的相互作用。在我们的研究中，从第30天起，MT C组的总抗氧化能力（TAS）增加，总氧化应激（TOS）降低，这反映了红氧平衡向增强方向的转变。大量文献记录表明，姜黄素能影响内源性抗氧化系统，包括调节超氧化物歧化酶（SOD）、过氧化氢酶（CAT）和谷胱甘肽过氧化物酶（GPx）18,32。这些途径在中和活性氧（ROS）、稳定细胞氧化还原稳态以及保护肾实质结构免受氧化损伤方面起核心作用。此外，姜黄素还能通过非酶促过程与ROS相互作用，例如螯合参与芬顿反应的过渡金属，从而减少高活性自由基的生成33。MT C组所观察到的TAS/TOS特征与这些已知的抗氧化机制一致，并支持姜黄素可能有助于在CKD中营造更有利氧化条件的观点。

鉴于肾脏疾病中氧化还原、炎症和凋亡通路的相互关联性，调节氧化负荷也可能影响下游的细胞反应。慢性炎症在慢性肾病（CKD）的进展中起核心作用。NF-κB是一种氧化还原敏感的转录因子，调节参与细胞因子产生、白细胞招募和纤维化的基因。在我们的研究中，MT组的NF-κB浓度保持在高水平，而在随访晚期，MT C组的NF-κB浓度有所下降。姜黄素已被广泛确认能够通过稳定kappa B抑制蛋白α（IκBα）并减弱促进NF-κB活化的氧化和炎症信号，从而抑制NF-κB信号通路。这些调控作用影响关键细胞因子（TNF-α、IL-1β和IL-6）的转录，并有助于形成较少促炎的肾内环境。MT C组观察到的NF-κB特征与姜黄素介导的氧化还原-炎症通路调节一致，并支持其调节CKD中炎症信号的潜力。

凋亡在肾细胞丧失和慢性肾脏病（CKD）进展中起着基础性作用。35,36 半胱天冬酶-3（Caspase-3）是凋亡级联反应中的关键执行酶，被广泛认可为可靠的凋亡生物标志物。16 在我们的研究中，MT 组的半胱天冬酶-3浓度持续升高，而在 MT+C 组中，从第45天开始直到第60天，半胱天冬酶-3呈现明显下降趋势。  

姜黄素被广泛认为是一种能够通过调节线粒体信号、减弱细胞色素 c 依赖的半胱天冬酶激活、稳定细胞内氧化还原状态来影响凋亡调控的因子。37,38 这些分子相互作用与促凋亡和抗凋亡信号之间的平衡密切相关，包括Bcl-2 相关 X 蛋白（Bax）和Bcl-2 的调控动态，它们对于肾小管上皮细胞完整性和存活至关重要。39 因此，MT+C 组观察到的半胱天冬酶-3变化与姜黄素介导的凋亡途径调控机制框架相符，并反映了支持肾组织内凋亡驱动下降的生化环境。

我们的研究存在若干局限性。样本量相对较小，这可能限制结果的普遍适用性。此外，尽管使用了多种指标评估肾功能和全身反应，但未进行肾脏组织病理学检查，而这本可以提供组织水平变化的直接证据。未来的研究应考虑更长的随访期，纳入组织学评估，并探索姜黄素在猫模型中的药代动力学，以优化剂量策略。健康对照组的设置旨在便于基线生理指标的比较，并为疾病相关的生物标志物变化提供背景参考。然而，对照动物数量有限，因此无法对群体水平的参考值得出明确结论，治疗相关的推论主要基于MT组与MT+C组之间的比较。

每个研究组的小样本量，由符合条件的3期CKD病例的可得性决定，限制了统计能力，并增加了假阴性和假阳性结果的风险。因此，我们的研究结果应被解读为初步的，并具有生成假设的作用。总之，在常规医疗治疗基础上，以口服方式每天每只猫80毫克分两次连续给药60天的咖喱素补充，与IRIS 3期CKD猫的较低SDMA浓度以及多种机制性生物标志物的有利变化相关。观察到的氧化应激、炎症和凋亡标志物的变化与咖喱素可能的辅助作用一致，但这些次要发现应被解读为生成假设。鉴于样本量较小，这些结果应被视为初步的，并需在更大规模、长期研究中，通过纳入直接肾功能和组织病理评估来进行确认。

## 材料与方法

## 伦理批准

我们的研究是按照动物实验的伦理原则进行的，并得到了阿塔图尔克大学动物实验地方伦理委员会的批准（批准号：66；批准日期：2021年4月12日；会议号：3）。在纳入研究前，所有参与猫的主人均签署了书面知情同意书。共有24只由客户饲养的家猫参与了本研究，包括8只临床健康的对照猫和16只处于IRIS第3期慢性肾病（CKD）的猫。慢性肾病（CKD）的诊断基于持续性氮质血症和临床表现，IRIS分期完全根据血清肌酐浓度进行（第3期为2.9-5.0 mg/dL）。SDMA浓度（≥26 μg/dL）被用作辅助生物标志物以确认慢性肾功能障碍，但未用于分期。存在肾前性氮质血症的猫在评估前已稳定，对于与慢性肾病（CKD）不一致的发现（如持续性等渗尿且SDMA正常）则被排除。

诊断标准还包括持续性同渗尿（尿比重（USG） < 1.035）以及临床表现，如多尿、多饮、体重下降和食欲减退。所有慢性肾病（CKD）猫在分期时临床状况稳定且未脱水，IRIS 分级是在肾功能变量稳定后进行的。出现肾前性氮质血症或脱水的猫最初通过液体疗法进行治疗，并在 72 小时后重新评估才纳入研究。大多数慢性肾病（CKD）病例在过去三个月内已被诊断，并在研究入组前维持在商业肾脏处方饮食上。患有伴随系统性疾病（如甲状腺功能亢进、糖尿病、肿瘤）或近期使用抗氧化剂或抗炎补充剂的猫被排除。在入组前，所有动物都进行了全面的体格检查、全血细胞计数（CBC）、血清生化检查、尿液分析和腹部超声检查。

## 研究设计和分组安排

该研究的主要结果是比较MT组和MT C组血清SDMA浓度的纵向变化，选择该指标是因为其在猫慢性肾病（CKD）中作为肾功能敏感标志物具有临床相关性。次要结果包括尿蛋白/肌酐比值（UPC）、氧化应激标志物（TAS、TOS）以及炎症和凋亡生物标志物（NF-κB、Caspase-3），评估这些指标旨在为主要终点提供机制性背景。共有24只猫被分为3个相等的组（每组n = 8），具体如下：对照组（Control）：临床上健康的猫，无CKD证据，经体格检查正常，血液学和生化检测结果正常，尿比重（USG）>1.035，肾脏超声表现正常。设立对照组旨在便于与CKD组进行基础生理比较，并为疾病相关的生物标志物变化提供背景参考。

医疗治疗组（MT）：被诊断为IRIS 3期慢性肾病（CKD）的猫只接受单纯医疗治疗，包括肾脏处方饮食、液体治疗、磷结合剂和降压药物，但不进行任何额外补充。姜黄素组（MT + C）：3期慢性肾病（CKD）的猫只接受与MT组相同的医疗治疗，并口服补充姜黄素（Solgar® 全谱姜黄素，土耳其伊斯坦布尔），剂量为每猫每日80毫克（分两次服用），连续60天。该配方为人类设计，含液体微粉化姜黄素（每胶囊含姜黄素40毫克），与食物同服以增强吸收。

猫咪在宠物之家兽医综合诊所接受治疗和监测。随机分组采用计算机生成序列进行。未对MT组提供安慰剂，但所有研究人员和实验室人员均被盲法对分组进行盲法。纳入健康对照组，以便与慢性肾病（CKD）组进行基线横断面比较，并在研究入站时表征氧化、炎症和凋亡生物标志物的疾病相关变化，尤其因为这些生物标志物在猫中尚未建立良好标准化参考范围。然而，健康对照组并非作为治疗疗效的比较工具。因此，治疗效果评估主要基于MT组与MT组C组之间的纵向比较。

## 治疗方案

在整个研究过程中，在Pethome Veterinary Polyclinic，对诊断为3期慢性肾脏病（CKD）的医疗治疗组（MT, n = 8）猫进行了操作。所有猫从第0天开始都喂食肾脏处方饮食（Unique Renal® Diet, 法国）。对于脱水的猫，根据体重给予乳酸林格液静脉注射，然后每隔一天进行皮下液体维持。通过使用自动化化学分析仪（Fuji NX 500 I, 富士胶片公司，东京，日本）测量总二氧化碳（TCO2）浓度来确定代谢性酸中毒，TCO₂浓度<15 mmol/L的猫被认为是酸中毒。1使用高清振荡仪（Hasvet 838 PM, Hasvet Medical, 伊斯坦布尔，土耳其）在第0天、第15天、第30天、第45天和第60天测量收缩压（SBP）。测量时猫处于胸卧位，使用合适尺寸的袖带（肢体周长的40%）置于前肢中段。所有测量均在安静的房间中进行，在5分钟的适应期后以尽量减少压力引起的变异。

在每个时间点，记录了5次连续读数，并使用最后3次测量的平均值进行分析。收缩压（SBP）≥ 160 mmHg的猫接受特米沙坦（Semintra® 4 mg/mL，德国勃林格殷格翰兽医制药公司）治疗，剂量为2 mg/kg/天，以将收缩压（SBP）降至160 mmHg以下。血清肌酐浓度和尿蛋白/肌酐比（UPC）在第0、15、30、45和60天评估。血清肌酐浓度使用生化分析仪（Fuji NX 500 I，富士胶片公司，日本东京）测量，UPC比值使用自动化化学分析仪（Catalyst One，IDEXX实验室，美国缅因州韦斯特布鲁克）测定。有蛋白尿的猫接受特米沙坦治疗，剂量为1 mg/kg/天。在饮食限制下仍持续高磷血症（血清磷浓度 > 4.6 mg/dL）的猫，口服给予碳酸镧（Antax® 500 mg，Vilsan制药公司，土耳其安卡拉），剂量为12.5 mg/kg/天，与食物混合。碳酸镧治疗至少在研究入组前4周开始，并在整个60天的研究期间保持剂量不变。

对于高钙血症（血清总钙浓度 > 12 mg/dL），肾脏饮食与维持饮食以1:1的比例混合以减少钙摄入。44 低钾血症猫接受葡萄糖酸钾或柠檬酸钾，口服剂量为1-2 mmol/kg/天。24 在食欲不振或体重减轻的情况下，米氮平（Zestat® 15 mg，赛诺菲安万特，土耳其伊斯坦布尔）按每48小时每只猫1.88 mg的剂量给予。45 对于呕吐，马洛匹坦柠檬酸盐（Cerenia®，Zoetis Inc.，美国密歇根州卡拉马祖）按1 mg/kg的剂量给予。46 在第0天诊断为贫血（血细胞比容（HCT） < 20%）的猫，接受达贝泊汀阿法（Aranesp®，Amgen Ilaç Tic. Ltd. Şti.，土耳其伊斯坦布尔），皮下给药，每周一次，剂量为0.5 μg/kg。所有接受达贝泊汀治疗的猫同时优化红细胞生成反应。

在第15天、第30天、第45天和第60天评估了持续治疗的必要性。MT C组的猫（n = 8）接受了上述相同的医疗治疗，同时口服姜黄素补充剂（Solgar® 全谱姜黄素，土耳其伊斯坦布尔），剂量为每只猫每天80毫克（分两次服用），连续60天。这种为人类设计的制剂含有液态微粉化姜黄素（每粒胶囊含姜黄素40毫克），相比传统粉末形式，可增强胃肠道吸收。为了确保与膳食脂肪共同摄入，从而提高生物利用度，该补充剂随食物给予。对照组的猫（n = 8）未接受任何医疗治疗。

## 样本采集

从所有猫咪采集血液和尿液样本，用于资格评估和纵向随访。对照组仅在基线（第0天）采集单一血液和尿液样本，以提供生理结果以供情境比较。在MT组和MT C组，样本采集时间点为5个时间点：第0天（治疗前）及第15、30、45和60天。每个时间点约抽取5毫升颈静脉血液，分布如下：0.5毫升入EDTA管进行血液学分析，0.5毫升入锂肝素管进行血浆分析，4毫升入血清管进行生化和分子分析。血清通过离心分离，压力为1006×克（相当于3000转/分钟），10分钟后储存于−80°C，直至检测（韩国Esco Lexicon® ULT冷冻机）。尿液样本在同一时间点（第0、15、30、45和60天）通过超声引导膀胱穿刺，使用22克针头和10毫升注射器采集。

## 常规实验室分析

血液学变量包括白细胞计数（WBC）、红细胞计数（RBC）、血红蛋白浓度和血细胞比容（HCT），采用EDTA抗凝血样并使用兽医血液学分析仪（迈瑞 BC-500，深圳迈瑞生物医疗电子股份有限公司，中国）测量。血清生化变量，如肌酐、磷（P）、钙（Ca）、钠（Na）、钾（K）和总二氧化碳（TCO₂），使用全自动生化分析仪（富士 NX 500 I，富士胶片公司，日本东京）进行分析。血清对称性二甲基精氨酸（SDMA）和尿蛋白-肌酐比（UPC）使用IDEXX Catalyst One化学分析仪（IDEXX实验室，美国缅因州韦斯特布鲁克）测定。尿比重（USG）使用兽医折光仪评估，每次使用前用蒸馏水校准。尿比重（USG） > 1.035 的氮质血症猫被归类为肾前性氮质血症。

## 氧化应激分析

使用市售的TAS和TOS比色法检测试剂盒（Rel Assay Diagnostics，土耳其加济安泰普；TAS 型号：RL0017，TOS 型号：RL0024）分析血清样本以评估氧化状态。所有测量在阿塔图尔克大学兽医学院生物化学系使用ELISA微孔板读数仪（BioTek Instruments，美国佛蒙特州Winooski）进行。TAS检测使用Trolox进行校准，结果以每升mmol Trolox当量（mmol Trolox equiv/L）表示，如先前所述。TOS检测使用过氧化氢，结果以每升mmol过氧化氢当量（mmol H₂O₂ equiv/L）表示，如先前所述。所有分析均按制造商说明进行二次重复测定。

## 炎症和凋亡标志物分析

使用猫专用ELISA试剂盒（猫NF-κB ELISA试剂盒，货号：DZE201280411；猫Caspase-3 ELISA试剂盒，货号：DZE201281041；上海太阳红生物技术有限公司，中国上海）测定血清中NF-κB和Caspase-3的浓度。实验在阿塔图尔克大学兽医学院生物化学系进行，使用微孔板读数仪（BioTek Instruments，美国佛蒙特州Winooski）。所有操作均严格按照生产商说明进行，每个样品均进行重复分析以保证准确性。研究中使用的所有ELISA试剂盒（TAS、TOS、NF-κB和Caspase-3）均按照良好实验室规范标准生产，并由各自生产商验证用于兽医或研究用途。因此，除了标准校准和重复验证外，不需要额外的内部验证。详细的分析特性，包括灵敏度、测定范围以及测定内与测定间变异系数，见表S1。

## 统计分析

所有统计分析均使用 IBM SPSS Statistics 25.0 版（IBM 公司，纽约州阿蒙克，美国）进行。首先使用 Shapiro–Wilk 检验评估数据的正态性。参数数据以平均值 ± 标准差表示，而非参数数据以中位数（最小值–最大值）表示。第 0 天 3 组（对照组、MT 组和 MT C 组）之间的基线比较，对于正态分布变量，使用单因素方差分析（ANOVA），随后进行 Tukey 事后检验。非正态分布变量使用 Kruskal–Wallis 检验分析，并使用 Mann–Whitney U 检验并结合 Bonferroni 校正进行成对比较。健康对照组仅在基线（第 0 天）采样。因此，所有涉及健康对照组的比较仅限于基线分析，旨在描述研究入组时的疾病相关差异。纵向治疗效果仅在两个 CKD 组（MT 组和 MT C 组）中评估。

对于这些重复测量，纵向结果使用线性混合效应模型进行分析，以考虑猫体内相关性及因随访丢失造成的缺失观察值。猫的身份被作为随机截距纳入。固定效应包括治疗组（MT 组 vs MT+C 组）、时间（第 0、15、30、45、60 天）以及组别 × 时间交互作用。模型假设通过残差图进行检验；如有需要，对结果进行对数转换以改善正态性和同方差性。多重性调整分别应用于基线横断面比较和纵向事后比较。主要终点为 SDMA。次要预先设定终点为 UPC、TAS、TOS、NF-κB 和 caspase-3；所有其他实验室变量及收缩压（SBP）均作为探索性分析。涉及健康对照组的基线比较被视为疾病特征分析的支持性分析，而疗效分析则基于 MT 组与 MT+C 组之间的纵向比较。

对于每个结果，在纵向分析中对各时间点之间或特定时间点各组之间的事后成对比较，均使用该结果内的Bonferroni校正进行调整。双侧P值<0.05被认为对主要终点有统计学意义；次要和探索性分析则被解释为假设生成性。
