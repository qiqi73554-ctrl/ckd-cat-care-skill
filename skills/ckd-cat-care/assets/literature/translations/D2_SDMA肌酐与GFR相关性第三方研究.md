使用相关系数、敏感性、特异性和受试者工作特征曲线评估了SDMA和血清肌酐(sCr)的诊断性能。与健康猫和糖尿病(DM)猫相比，慢性肾病(CKD)猫的血浆SDMA显著升高（26.7 ± 9.9 μg/dL），血清肌酐也显著升高（249.7 ± 71.6 μmol/L [2.8 ± 0.8 mg/dL]；两者均 P < .001）。血浆SDMA(τB = −0.57；P < .001)和sCr(τB = −0.56；P < .001)与肾小球滤过率(GFR)显著相关。血浆SDMA(τB = 0.52；P < .001)与sCr存在显著关系。血浆SDMA和sCr在检测肾功能下降方面的敏感性相似，分别为76%-94%和71%-88%。肌酐的特异性高于血浆SDMA，分别为94%-96%和75%-76%（P < .05）。

## 希望早期治疗会

延缓疾病的自然进展过程，使早期诊断变得重要，并且对老年猫（11-14岁）和高龄猫（≥15岁）进行定期健康筛查是必不可少的。通过测量肾小球滤过率（GFR）评估早期肾功能下降是金标准，但慢性肾病（CKD）通常通过全面的体格检查、广泛的实验室检测（包括全血计数、血清生化分析和尿液分析）、影像学诊断以及血压测量的组合来诊断。兼容的临床症状、持续的氮质血症以及尿液浓缩能力下降（尿比重（USG）[USG] < 1.035）表明氮质血症性慢性肾病（CKD）的开始。

## 肾存在

氮质血症反映了50%至75%功能性肾单位的不可逆丧失，与肾功能下降50%至60%相关。这种差异归因于剩余肾单位的代偿性超滤。为了维持稳态，肾单位数量的减少导致幸存肾单位的灌注和滤过增加。在短期内，代偿性超滤是有益的，因为肾小球滤过率（GFR）部分得以维持，但从长期来看，这可能是有害的，因为它促进了肾小球内高血压，最终导致慢性肾病（CKD）的进展。尽管在CKD早期阶段GFR下降可能已经相当明显，但血清肌酐（sCr）不一定会超过参考区间（RI）的上限。

此外，肾外因素可能会干扰常规生物标志物的结果，血肌酐会受到饮食、年龄、性别和肌肉量的影响。

此外，血清肌酐有很高的个体间差异，因此参考范围通常较宽。

高个体间变异性的一个结果是，使用基于人群的参考范围（RI）时，血清肌酐（sCr）并不是识别早期慢性肾病（CKD）的敏感生物标志物。

## 这些限制造成了一个

迫切需要敏感的标志物在氮质血症出现之前识别肾功能受损。对称性二甲基精氨酸（SDMA）是蛋白质甲基化的副产物，进入循环后其排泄主要通过肾脏（>90%），通过肾小球滤过和主动分泌完成。不存在重吸收。在小型动物中，SDMA不受肌肉量或性别影响，这相对于血清肌酐（sCr）具有优势。据称，SDMA在检测肾功能障碍方面的敏感性优于sCr。这主要基于一项回顾性研究，该研究包括42只慢性肾病（CKD）和健康老年猫，其中SDMA（临界值14 μg/dL）在识别肾小球滤过率（GFR）下降 >30% 时显示出比sCr（临界值185 μmol/L [2.1 mg/dL]）更高的敏感性。SDMA与GFR之间的相关性（r = −0.79；P < .001）被证明与sCr与GFR之间的相关性（r = −0.77；P < .001）相当，表明这两种肾功能标志物与GFR密切相关。 

## 这一发现

这也得到了其他研究的证实，这些研究获得了SDMA与GFR之间的决定系数（R2 = 0.82；P < .001），与sCr与GFR之间的关系相似（R2 = 0.81；P < .001）。由于关于SDMA在猫中诊断性能的研究有限，本研究旨在验证SDMA在检测GFR受损方面是否比sCr具有额外价值。我们的第一个目标是比较这些生物标志物与GFR之间相关性的强度。第二个目标是评估SDMA和sCr的敏感性、特异性以及最佳截断值。

## 材料与方法 研究样本与设计

这项回顾性研究在兽医学院小动物科进行。使用了来自成年、私人饲养猫的冷冻血样（−80°C），这些猫曾作为先前已发表前瞻性研究的一部分接受过肾小球滤过率（GFR）估算和一般健康检查。这些猫是在2009年至2014年5年期间招募的。根据全面体格检查和常规实验室分析的结果，所有动物被分类到3个预先定义的组中的1个：慢性肾病（CKD）、糖尿病（DM）和健康对照组。CKD的存在是通过血肌酐（sCr）值高于参考范围（>161.8 μmol/L [>1.83 mg/dL]）结合尿比重（USG）<1.035（肾性氮质血症）以及兼容的病史和相关临床症状来确定的。

## 糖尿病（DM）的诊断

一直基于高血糖、尿糖、血清果糖胺浓度升高以及典型临床症状的组合。健康对照组的猫在体格检查、血液检查（全血细胞计数、血清生化分析和总甲状腺素浓度）以及尿液分析（包括尿蛋白：肌酐比值和细菌培养）中均未显示任何显著异常。

主要招募兽医学系的教职员工和学生参与所述的前瞻性研究项目。所有猫的病例档案中回顾性提取了信号数据、尿比重（USG）、总甲状腺素值、血肌酐（sCr）浓度以及通过外源性碘苯曲莫尼（exo-iohexol）清除测定的肾小球滤过率（GFR）结果。对剩余血浆样本回顾性测定了对称二甲基精氨酸（SDMA）浓度。未知血肌酐或exo-iohexol GFR结果的动物以及血浆样本不足的猫被排除在研究之外。最近，在一组甲状腺功能亢进猫中发现SDMA与GFR之间存在非显著性关系，可能是由于血液中甲状腺素的变化可能同时影响SDMA的生成和代谢，而与GFR无关。

## 肾小球滤过率（GFR）

肾小球滤过率（GFR）是通过联合血浆外源肌酐和伊俄昔醇清除测试（PEC‐ICT）测量的。简而言之，静脉注射了64.7 mg/kg的外源伊俄昔醇和40 mg/kg的肌酐。在注射前以及注射后5、15、30、60、90、120、180、360和600分钟采集了乙二胺四乙酸（EDTA）血浆样本。在我们的研究中，仅使用了外源伊俄昔醇清除值。外源伊俄昔醇的血浆水平通过高效液相色谱结合紫外检测法进行分析。药代动力学分析使用WinNonlin（WinNonlin版本4.0.1，Scientific Consulting Inc，Apex，NC）进行。血浆数据使用统计矩方法进行非房室分析。

血浆浓度-时间曲线下面积（AUC）已按照Watson等人所述，使用梯形法并外推至无穷大计算。

## 肾功能测试之间的相关性

肯德尔秩相关系数（τB）显示，在49只猫中，SDMA血浆浓度与GFR之间的相关性为中等（τB = −0.57；P < .001）；然而，sCr与GFR的相关性大小相同（τB = −0.56；P < .001）。两种生物标志物的高浓度均与滤过率降低相关。两种肾脏生物标志物SDMA血浆浓度和sCr之间的相关性也为中等（τB = 0.52；P < .001）。

## 基于SDMA具有优越性的说法

与血清肌酐（sCr）相比，SDMA 对检测真实功能障碍更为敏感，因此预计 SDMA 与肾小球滤过率（GFR）之间的相关性会比 sCr 与 GFR 的相关性更强。相反，我们观察到血浆 SDMA 和 sCr 与肾清除率的相关性相同。两种生物标志物都值得作为 GFR 测量的替代指标，以客观评估肾功能。随着肾清除率下降，血浆 SDMA 增加，但两者并非完全相关。SDMA 结果的变化不能完全归因于肾滤过功能的变化，SDMA 分子的代谢或清除中的其他因素也必须被考虑。截至目前，系统性疾病或治疗对 SDMA 浓度的影响在小动物中研究甚少。最近对甲状腺功能亢进猫的研究显示，SDMA 与 GFR 值之间的相关性较差，可能是由于猫的甲状腺功能亢进状态导致蛋白质代谢发生变化。

## 因此，我们排除了

基于多种诊断工具，包括血清总甲状腺素的测定，诊断甲状腺功能亢进。在少数猫中，甲状腺素数值缺失，但根据它们的年轻年龄、缺乏相关临床症状以及甲状腺触诊正常，甲状腺功能亢进的诊断不太可能。在本研究中，大量肾小球滤过率（GFR）正常的动物患有糖尿病（DM），因此不能排除这种内分泌疾病对血浆SDMA的肾外影响。然而，我们无法证明健康对照组与非氮质血症DM猫的SDMA血液浓度存在显著差异。已有报道显示，（控制不充分的）DM对SDMA浓度的影响表现为DM猫（无合并症）的SDMA血水平显著低于健康对照动物，可能是由于高滤过和渗透作用。由于该研究未测量GFR，因此这些发现难以解释。仍需进一步研究以确定糖尿病是否会影响猫的SDMA浓度。

散点图显示了所有SDMA和sCr的结果，显示出几处不一致的结果。GFR值表明，大多数SDMA高而sCr正常的猫其SDMA结果为假阳性，这反映在SDMA的特异性略低（76%）相比sCr（94%‐96%）。使用RI上限（sCr为161.8 μmol/L [1.83 mg/dL]，SDMA为14 μg/dL），sCr仅产生了最少的假阳性测试结果（n = 1），而SDMA错误地怀疑更多健康猫存在肾功能下降（n = 7）。如预期所示，这两种肾脏生物标志物的敏感性和特异性部分受GFR截断值影响。边界GFR截断值通常比低GFR截断值产生更少的SDMA和sCr假阳性测试结果。记录到在2只猫中，尽管SDMA结果正常，sCr仍然升高。两只猫的GFR值下降，表明SDMA结果为假阴性。

然而，本研究中sCr与SDMA在敏感性上的感知差异在临床上并不具有重要意义。SDMA和sCr都能正确识别肾功能丧失晚期的猫（<1.2 mL/[min kg]）。总体而言，需要注意的是，sCr和SDMA在敏感性和特异性上的轻微差异很可能归因于它们的参考区间（RI），因为两种生物标志物在ROC曲线分析中的表现相同。根据我们的数据，与长期使用的sCr相比，SDMA提供的额外诊断价值很有限。在检测GFR <1.7 mL/(min kg)和GFR <1.2 mL/(min kg)的准确性方面进行了研究，随着肾功能受损的进展，两种标志物的诊断性能都得到了提高。然而，SDMA在商业上被宣传为一种高敏感度的诊断工具，在检测那些使用传统肾标志物sCr被遗漏的早期肾功能丧失猫方面提供了额外价值。

由于多种原因，我们的研究结果并不完全符合以往的研究。在各项研究中，SDMA 的临界值保持不变，但由于各实验室在建立参考区间（RI）时选择的样本不同，血肌酐（sCr）的参考区间差异很大。这影响了血肌酐的敏感性。上限参考值越高，就会产生越多的假阴性测试结果，最终导致该生物标志物的敏感性降低。我们的血肌酐参考区间由 Ghys 等人确定，其重要优势在于具有实验室特异性，但与其他研究相比，血肌酐的上限参考值相对较低。此外，由于使用不同的实验室定量技术测定血肌酐（酶法 vs 比色法）以及肾小球滤过率（GFR）（标记物和采样策略）的不同，也可能产生分析变异。这使得各项研究之间的比较变得具有挑战性。我们的研究为横断面回顾性研究，因此无法对动物进行长期随访。

这导致了一个额外的不利因素，即我们没有足够的数据来记录猫在出现氮质血症之前进入IRIS第一阶段的情况，因此无法评估用于这一目的的生物标志物。通过使用ROC曲线，我们评估了SDMA（14 μg/dL）和血清肌酐（sCr，161.8 μmol/L [1.83 mg/dL]）的阈值，但对于包含慢性肾病（CKD）和非CKD猫的数据集，并不理想。针对SDMA的一个能产生更优敏感性和特异性组合的切点是18 μg/dL。以预设切点14 μg/dL的对称二甲基精氨酸（SDMA）产生了许多假阳性结果。由于敏感性和特异性密切相关，18 μg/dL的切点固有地导致敏感性略有下降，但这一不利因素是有限的，并有利于提高特异性。在临床稳定、充分水化的动物（排除了肾前或肾后问题）的情况下，在CKD诊断得到确认后，最近更新的IRIS指南允许通过至少两次空腹测量SDMA和sCr来分期慢性肾病（CKD）。

对称性二甲基精氨酸反复超过18 μg/dL（即使血清肌酐水平正常）表明动物至少患有慢性肾病（CKD）2期。

## 既然我们的研究做了

由于未包括对 SDMA 和 sCr 的连续监测，我们的结果无法与 IRIS 分期系统直接比较。对于 sCr，更偏向使用稍低的阈值 155.6 μmol/L（1.76 mg/dL）。由于在我们研究的猫样本中 sCr 的特异性较高，因此希望提高敏感性，即使会造成轻微的损失。尽管本研究具有回顾性性质，但我们的大多数数据（sCr 和 GFR）来源于之前前瞻性研究中招募的猫。

## 所有包含的猫都接受了相同的

方案：包括一般体格检查、血液和尿液检测以及GFR清除率测试。这减少了本研究回顾性特性的局限性。本研究最重要的纳入标准是必须有足够的残余血液样本以便进行SDMA分析，这意味着49只猫并非随机选取。这在获得具有代表性的研究样本方面是不利的。我们旨在在非氮质血症和氮质血症猫样本中测试SDMA和血清肌酐（sCr）的准确性。肾功能标志物在晚期肾衰竭（IRIS III/IV期）中的表现更佳，而生物标志物的挑战和附加价值主要基于其识别轻度GFR损失动物的能力。

## 在所有猫中，有五只达到了

肾清除率在1.2至1.7 mL/(分钟·公斤)之间，表明存在轻度肾功能损害。此外，早期慢性肾病（CKD）猫的数量较少可能解释了在我们的数据集中无法确定SDMA的额外诊断价值，需要进一步研究。猫被分配到不同亚组是基于体格检查和常规实验室分析。但当考虑到肾小球滤过率（GFR）结果时，最初被认为健康的3只猫和2只糖尿病猫被发现具有轻度肾功能损害。另一方面，慢性肾病（CKD）组中有1只猫的GFR值>1.7 mL/(分钟·公斤)。用于SDMA分析的血液残留冻存样本最长保存了8年。已经有研究报道了该分子在血液中的短期稳定性。

长期保存对 SDMA 精确分析的影响是一个尚未明确的问题。此外，几个血浆样本（n = 5）在 SDMA 分析前进行了 1 次冻融循环。多次冻融循环不会对 SDMA 产生显著变化。此外，IDEXX 声称如果样品冷冻，该分子可以保持稳定数年。对称二甲基精氨酸（SDMA）的浓度是使用免疫分析“SDMA IDEXX 测试”进行定量的，而非黄金标准液相色谱-质谱联用法（LC-MS）。SDMA IDEXX 测试使用葡萄糖-6-磷酸脱氢酶缀合物和单克隆抗 SDMA 抗体，比 LC-MS 成本更低、耗时更短，并且目前在商业兽医实验室中被广泛使用。这意味着我们研究的结果具有临床上适用于兽医实践的优势。IDEXX SDMA 测试是一种准确的技术。

在10到45 μg/dL的范围内，最大测量误差估计为1到3 μg/dL。

## 此外，

测试对血脂过高、黄疸或轻度至中度溶血不敏感，这些通常出现在采血过程中。在这项回顾性研究中，SDMA 被证明是检测猫肾功能受损的准确生物标志物，其定义依据为外源性碘扎醇清除率。然而，在当前这批成年非氮质血症和氮质血症猫样本中，我们无法证明 SDMA 相较于传统的血清肌酐（sCr）生物标志物具有显著的额外价值。两种分子的诊断价值大致相当，并在肾功能障碍的晚期阶段有所提高。
