## 猫肾脏中肾钙沉积与肾结石的共现

Nuttha Hengtrakul 1, Eva Furrow 2, Ferenc Toth 3, Michael Borofsky 4, Jody P Lulich 5,✉ 肾钙沉积在患有肾结石的猫中很常见。了解这些疾病之间的关联可能有助于理解它们的发病机制。

## 假设/目标

肾钙沉积与肾结石相关。对175只有主人的猫进行了死后肾脏评估。这是一项观察性横断面研究。高分辨率微射线摄影识别了肾结石，并将实质性矿化分为条纹状或点状。在微射线照片上量化了矿化百分比。使用卡方检验和逻辑回归（带比值比[OR]和95%置信区间[CI]）估计了猫水平（左或右肾任一肾发病）和单个肾水平肾钙沉积与肾结石的关联。54%的猫（95/175）存在肾结石，84%（147/175）存在肾钙沉积。患肾结石的猫比未患猫年龄更大（中位数，15岁对13岁；P = .004）。在猫水平，肾钙沉积与肾结石的发生风险较高相关（OR，3.5；95% CI，1.6-7.4；P = .002），但在调整年龄后，该关联减弱（OR，3.1；95% CI，1.0-10.1；P = .05；n = 115）。

在肾脏水平上，条纹状矿化与肾结石相关（OR，13.9；95% CI，2.0-95.9；P = .01），而点状矿化与肾结石无显著相关性。患有肾结石的猫的矿化百分比高于未患有肾结石的猫（P = .004）。

## 结论与临床重要性

肾钙沉（特别是条纹状髓乳头样模式）与猫的肾结石形成有关。特定模式的矿化可能是管理肾结石的预防目标。关键词：草酸钙、磷酸钙、矿化、X射线、尿结石。肾钙沉和肾结石是影响猫肾脏的两种不同矿化形式。肾钙沉是钙盐沉积于肾实质，而肾结石涉及肾盂内单独矿物结晶的形成。在患有慢性肾病（CKD）的老年猫中，61%-78%的病例存在肾钙沉。患有CKD的猫中肾结石的发生率略低，最高可达51%。肾钙沉和肾结石都具有高钙血症和高钙尿症等风险因素，但猫中肾钙沉与肾结石之间的关系尚未完全明了。

在人类中，促进肾结石形成的一种假设机制涉及一种特定形式的肾钙质沉着，即在亨利氏袢或集合管基底膜内形成的磷酸钙（CaP）沉积。8,9 当这些沉积延伸到乳头尖端并暴露于肾盂的尿液中时，它们成为异质成核的位点。10 通过提供初始晶体形成的表面，这些沉积在较低尿液过饱和水平下促进肾结石的形成。11 类似机制是否在猫的肾结石形成中起作用尚不清楚。我们回顾性研究评估了猫肾中肾钙质沉着与肾结石的共现情况。我们还评估了肾钙质沉着的特定模式是否与肾结石相关。我们的假设是，患有... 的猫更常发生肾结石。

## 材料与方法

一项观察性横断面研究估计了猫中肾结石和肾钙化的共现情况，使用了2016年7月1日至2024年12月31日期间在兽医教学医院收集的死后肾脏（补充附录A）。供体包括来自转诊和初级护理服务的客户自有猫。肾脏在安乐死后立即或在冷藏尸体（4°C）中24小时内采集，并保存在10%福尔马林中≥24小时，直到成像和处理完成。由于使用的是尸体组织，该项目免于机构动物护理和使用委员会的监督。研究队列包括两只肾脏均可获得的猫。严重自溶或明显畸形的肾脏被排除在外。

## 猫肾钙沉积与肾结石的关联

在患有肾钙质沉着的猫中，60%（88/147）有肾结石，而在没有肾钙质沉着的猫中为25%（7/28）（P = .001）。在进行量化微放射摄影的子集中（n = 158），有肾结石的猫的矿化百分比较高（中位数，0.5%；四分位间距，0.2%-0.9%；n = 75），而无肾结石的猫为（中位数，0.3%；四分位间距，0%-0.6%；n = 83；P = .004）。在单变量逻辑回归分析中，肾钙质沉着与肾结石相关（OR，3.5；95% CI，1.6-7.4；P = .002；n = 175；表3）。双侧肾钙质沉着显示出更强的关联（OR，5.1；95% CI，2.0-12.8；P < .001），而单侧肾钙质沉着则未显著相关（OR，2.3；95% CI，0.4-12.6；P = .36）。年龄与肾结石相关（OR，1.2；95% CI，1.1-1.3；P = .001；n = 115）。

在提供年龄的情况下，使用两个混合效应逻辑回归模型评估肾钙化模式与肾结石之间的关联（图 S3）。将年龄纳入为固定效应，个体猫纳入为随机效应，以考虑猫体内的簇集效应。在 230 个肾脏中，有 186 个存在肾钙化。在第一个模型中，肾脏被分为三个互斥的组：条纹状、点状以及条纹状和点状的组合。条纹状肾钙化（OR, 13.9；95% CI, 2.0-95.9；P = .01）和组合模式（OR, 18.6；95% CI, 2.2-160；P = .01）与肾结石的发生几率更高相关。对于点状肾钙化，估计不准确且未达到显著性（OR, 6.7；95% CI, 0.2-26；P = .30）。在该模型中，年龄与肾结石的发生未显示显著相关性（OR, 1.1；95% CI, 1.0-1.3；P = .11）。

在第二个模型中，肾脏根据条纹状或点状肾钙化的存在进行分组，而不考虑重叠；因此，组之间并非互斥。条纹状肾钙化仍与肾结石相关（OR，10.0；95% CI，1.8-54.8；P = .01）。相比之下，点状肾钙化与肾结石没有显著相关性（OR，1.7；95% CI，0.4-6.7；P = .44）。在该模型中，年龄并不显著（OR，1.1；95% CI，1.0-1.3；P = .07）。肾钙化在猫中常与肾结石同时发生。在有肾钙化的肾脏中，49%有肾结石。这两种情况之间的生物学机制尚未完全理解，但可能来源于共享的潜在原因。这两种病理性矿化形式在慢性肾脏疾病（CKD）中很常见，表明系统性因素如肾脏损伤、矿物质代谢和排泄紊乱或年龄增长可能促进这两种状态的发展。肾钙化可能是促进肾结石形成的一个合理催化因素。

然而，我们的研究无法确定肾钙质沉着是否先于人类广泛接受的假设提出，在肾间质（兰德尔斑）或肾小管（兰德尔栓）的CaP沉积物一旦暴露于尿液中，会成为CaOx结石形成的起始点。在猫中，条纹状肾钙质沉着在形态上似乎与该假设一致，我们的研究结果表明，条纹状模式与肾结石的存在相关。如果实质性矿化的线状轨迹暴露于尿液空间，它们也可以成为初始肾结石形成的位点。支持这一假设，一些猫的CaOx肾结石含有类似钙化小管的CaP核心，本研究中的一例肾结石也证实了这一点（图2）。与这一概念一致的是，微放射线条纹与组织病理学子集中的冯·科萨阳性矿化在肾乳头或肾髓质中有关，支持主要为髓乳头分布。

相比之下，点状肾钙化，可能反映由于血管或肾小球损伤导致的营养不良性钙化，并未与肾结石形成相关。微放射图像的点状模式与皮质或皮质髓质交界区的von Kossa染色没有显著相关，这可能反映了仅点状组样本量较小而统计能力有限。尽管无法确定因果关系，但髓乳头的矿化占优势及其与集合系统的解剖接近性强调乳头是组织矿化可能为肾结石附着和生长提供物质基础的合理部位。

或者，肾钙沉积和肾结石也可能源于不同但相互重叠的机制。两者在老年猫中都很常见，表明它们可能代表与年龄相关的肾损伤的平行结果。肾钙沉积通常涉及钙在肾间质或肾小管内的沉积，而肾结石则依赖于晶体在尿液空间内的滞留。如果缺乏其他促成因素，如尿液过饱和或流动动力学改变，肾脏可能显示弥漫性矿化而不会形成肾结石。本研究中发现的54%的肾结石患病率与此前报道相符。尽管这一比例高于美国一项693只住院猫研究中报告的7%患病率，但这种差异可能反映了研究人群和诊断敏感性上的不同。我们的队列年龄较大（中位数14岁）相比一般住院猫群体（中位数10岁），并且我们使用了高分辨率微放射摄影。

这种先进的成像技术能够检测到常规临床放射学和超声检查中常常被忽视的微小或亚临床矿化。这些发现强调了肾结石在老年猫群体中是一个重要负担，特别是考虑到在73%的受影响肾脏中，尿路结石被确定为阻塞的原因。21 草酸钙是猫最常见的肾结石类型。从2022年到2023年，明尼苏达尿石中心分析了来自超过45,000只猫的尿石；其中765份标本来自肾脏或输尿管。76%的上尿路尿石由草酸钙组成。22 对2445例上尿路尿石的历史分析同样报道了70%为草酸钙。23,24 这些发现强调了草酸钙肾结石的临床重要性。在我们的研究中，尿石成分仅对一个小的随机选择子集（n = 10）可用，其中5/10的肾结石为磷酸钙。鉴于样本量有限，这些结果并不旨在估算更大群体的成分流行率。

我们的回顾性研究存在一些局限性。所检查的肾脏来自被安乐死的猫，通常是由于慢性或终末期疾病。因此，我们的发现可能相比健康或较年轻的猫，过度反映了肾脏矿化的发生率。尽管如此，我们的研究提供了大量完整肾脏的宝贵机会，使我们能够详细评估疾病各阶段的矿化模式和负担。尽管高分辨率微放射摄影使肾结石和肾钙化物可以被敏感检测，但可能无法发现非放射性尿石。此外，一些肾脏在成像前移除了一个小的中央切片。总体的矿化模式仍然可以评估，但局灶性矿化或局限于切除区域的小结石可能被遗漏。

肾钙化病是指肾组织中钙盐（通常为CaP或CaOx）沉积。25 在我们的研究中，冯·科萨染色确认了钙盐的存在。此前使用冯·科萨和阿利扎林红S染色的研究表明，猫的肾钙化病主要由CaP组成。26 安乐死时临床病理学数据尚无，限制了我们利用生化数据评估矿物质平衡的能力。由于肾脏斑点性肾钙化病的肾脏数量较少，其估计不精确。横断面设计排除了时间推断。总之，肾钙化病与猫的肾石化有关。条纹状肾钙化病模式与单个肾脏中的肾石有关。未来的研究有望帮助澄清条纹矿化与肾结石形成之间的机制关系。理解条纹化矿化的机制并加以减缓其发展，可能为预防猫的肾结石病提供潜在目标。
