## 金智贤 1,2, 尹永民 1,✉

血清猫胰腺脂肪酶（fPL）用于诊断胰腺炎，但解读具有挑战性，因为fPL可能受非胰腺疾病的影响，包括肾功能下降。旨在评估猫慢性肾病（CKD）分期与血清fPL的关联，并描述肾功能生物标志物与fPL的关系。本回顾性研究评估了2024年2月至2025年3月期间送至二级转诊兽医医院的猫的病历。纳入条件要求在同一天完成全血计数、血清生化、血气分析、尿液分析、血清fPL及腹部超声检查。CKD分期遵循国际肾脏关切学会指南，使用血清肌酐、尿液比重（USG）及超声检查。采用Kruskal-Wallis检验进行非参数组比较，并使用Spearman相关分析评估fPL与肾功能生物标志物之间的关联。

随着CKD分期的进展，fPL显著增加（p < 0.001）。此外，fPL与血尿素氮（BUN）（ρ = 0.516, p < 0.001）、肌酐（ρ = 0.459, p < 0.001）和无机磷（ρ = 0.312, p < 0.001）呈正相关。此外，fPL与尿比重（USG）呈负相关（ρ = −0.502, p < 0.001）。游离钙与fPL无相关性（ρ = 0.012, p = 0.898）。

## 结论与相关性

在这项临床队列研究中，较高的慢性肾病（CKD）分期与较高的血清fPL水平相关。由于单独fPL不足以诊断胰腺炎，且其水平可能因肾功能下降而升高，因此在患有CKD的猫中，轻度至中度fPL升高应结合临床症状和胰腺影像学检查结果进行解读。关键词：猫科医学，肾功能不全，氮质血症，胰腺炎，脂肪酶

慢性肾病（CKD）是影响老年猫最常见的疾病之一。在10岁以上的猫中，其报告的患病率超过30%–40% [1,2,3,4,5]。CKD的常见病史和临床症状包括体重下降、多尿、多饮以及持续低尿比重（USG）（USG；< 1.035）[6,7,8,9]。根据国际猫科医学协会的共识指南，猫慢性肾病（CKD）的临床诊断是基于氮质血症伴随尿液浓缩不足来确定的 [10]。

猫胰腺炎，曾被认为是一种罕见的临床实体，如今已被认为是一种常见疾病，其发生率与人类和犬类相当。2007年一项涉及115例猫尸检的组织病理学研究显示，67%的参与者有胰腺炎的证据；其中慢性胰腺炎、急性胰腺炎（AP）和急性加慢性胰腺炎分别占50.4%、6.1%和9.6%。此外，45%的临床健康猫显示组织病理学上的胰腺炎迹象[11]。血清猫胰腺脂肪酶（fPL）浓度已成为猫胰腺炎非创伤性诊断的敏感且特异的生物标志物[12,13,14,15]。

在人类医学中，大量证据表明尿毒症会对胰腺产生不利影响 [16,17,18]。已有研究记录了终末期肾病（ESRD）与急性胰腺炎（AP）之间的密切关联 [19,20]。一项在德国进行的全国性队列研究，涉及超过70,000名接受血液透析的ESRD患者，报告的急性胰腺炎年发病率为每10万人中67例。这明显高于普通人群中每10万人中19.7例的发病率 [21]。类似地，一项在台湾进行、包括2,603名ESRD患者的前瞻性队列研究发现，ESRD患者中急性胰腺炎的发病率比普通人群高出三倍以上。已经提出了几种病理生理机制来解释这种关系。一种假设认为，腹膜透析液中的钙可能通过腹膜扩散，导致胰腺局部高钙血症，并进一步加重胰腺功能障碍 [22]。

此外，在肾功能不全中发生的胃肠激素浓度增加，如胆囊收缩素、胃抑制多肽和胰高血糖素，可能刺激胰腺酶的过度分泌并导致胰腺损伤 [23]。尽管在人类中已公认肾功能障碍与胰腺炎之间存在关联，但慢性肾病（CKD）与猫胰腺炎之间的关系仍难以明确。重要的是，猫胰腺炎的诊断具有挑战性，通常依赖于临床症状、实验室异常和影像学发现的综合判断，而不是单一生物标志物。此外，胰腺脂肪酶部分通过肾脏清除；因此，即使在没有原发性胰腺炎症的情况下，肾小球滤过率（GFR）下降也可能导致测得的脂肪酶浓度升高。

因此，本研究旨在评估血清 fPL 浓度在不同慢性肾病（CKD）阶段的变化，以及 fPL 与猫常规测量的肾脏生物标志物的关系。我们假设 fPL 浓度会与肾功能下降的标志物相关，从而强调在有 CKD 的猫中解读 fPL 需要谨慎。

## 纳入标准

如果猫咪接受了包括全血细胞计数（CBC）、血气分析、血清生化检查、血清fPL浓度测定、尿液分析以及腹部超声在内的综合诊断评估，并且这些检查与临床检查在同一天进行，则其有资格被纳入研究。CBC使用自动血液分析仪（ProCyte Dx；IDEXX Laboratories，美国）进行。血清生物化学分析使用自动干式生化分析仪（FUJI DRY-CHEM NX700；富士胶片，日本）进行。尿液分析，包括尿比重（USG）测量，是在腹部超声初步诊断评估时，通过膀胱穿刺获得的尿样使用折光仪进行测定，且在治疗干预前完成。腹部超声检查使用配备12 MHz线性探头的超声系统（ProSound α7；日立Aloka Medical，日本）进行。

作为常规临床护理的一部分，检查由获得认证的兽医放射学专家进行，通常包括对多个腹部器官的评估，包括肾脏和胰腺。然而，胰腺超声检查结果和符合胰腺炎的标准化临床症状在各个病例中未被一致记录，因此，在本分析中未用于定义胰腺炎。在研究期间，共有169只猫符合初步纳入标准。

## 临床评估

根据血清肌酐浓度、尿比重（USG）和肾脏超声检查结果，将这112只猫分为五组。正常组的血清肌酐浓度 < 1.6 mg/dL，尿比重（USG） ≥ 1.035，且肾脏超声未发现任何异常。慢性肾病（CKD）分期依据2019年国际肾脏兴趣学会（IRIS）指南进行：第1期的特点是血清肌酐浓度 < 1.6 mg/dL且尿比重（USG） < 1.035；第2期为血清肌酐浓度在1.6至2.8 mg/dL之间；第3期为血清肌酐浓度在2.9至5.0 mg/dL之间；第4期为血清肌酐浓度 > 5.0 mg/dL。这个操作性定义用于识别早期CKD（第1期），其特征是尿液浓缩能力不足但没有氮质血症，并代表了IRIS分期系统的研究特定修改，其中使用尿比重（USG）进行CKD诊断而非正式分期 [10]。

被认为与慢性肾病（CKD）一致的肾脏超声异常包括皮质回声增强、皮质髓质分界消失、肾轮廓不规则以及肾脏缩小[24]。血清fPL浓度使用Vcheck fPL（Bionote）定量免疫测定法测量，这是一种用于fPL检测的荧光免疫层析测定法。该测定法可在15分钟内提供定量结果，动态测量范围为1–30 ng/mL。根据制造商的建议，数值≤ 3.5、3.6–5.3和≥ 5.4 ng/mL分别被分类为正常、可疑以及超过测定法临界值。

## CKD 分期与 fPL 的关联

血清 fPL 浓度在不同 CKD 阶段存在差异，CKD 越晚期的猫，其 fPL 值越高（图 5）。中位 fPL 浓度随 CKD 阶段的进展逐渐升高：正常：1.95 ng/mL（四分位距，1.4–3.325；95% 置信区间，1.87–5.27）；第1阶段：3.60 ng/mL（四分位距，2.6–5.3；95% 置信区间，1.62–9.58）；第2阶段：4.4 ng/mL（四分位距，1.7–7.2；95% 置信区间，3.98–10.84）；第3阶段：5.1 ng/mL（四分位距，4.1–17.8；95% 置信区间，4.15–14.94）；第4阶段：6.05 ng/mL（四分位距，5.225–10.125；95% 置信区间，5.40–18.35）。图 5. 猫不同 CKD 阶段 fPL 浓度分布。箱型图显示了 112 只猫按照 CKD IRIS 阶段的 fPL 浓度分布情况。

随着慢性肾病（CKD）阶段的进展，猫的fPL浓度呈渐进性增加。在CKD第3和第4阶段的猫中观察到显著更高的fPL浓度。fPL，猫胰脂肪酶；CKD，慢性肾病（CKD）；IRIS，国际肾脏研究协会。Kruskal–Wallis检验显示不同CKD阶段的fPL浓度存在显著差异（H = 26.80，p < 0.001）。事后成对比较显示，与正常组相比，各CKD阶段的fPL浓度都显著升高（第1阶段：p = 0.04；第2阶段：p = 0.04；第3阶段：p < 0.01；第4阶段：p < 0.01）。然而，相邻CKD阶段之间未观察到显著差异（第1阶段 vs 第2阶段，p = 0.95；第2阶段 vs 第3阶段，p = 0.17；第3阶段 vs 第4阶段，p = 0.48）。在早期与晚期CKD之间也存在显著差异，第4阶段的fPL浓度高于第1阶段（p = 0.02），并与第2阶段比较呈边界性差异（p = 0.05）。

本研究评估了猫血清fPL浓度与CKD严重程度之间的关联，以及它们与常用肾脏生物标志物的关系。血清fPL随着CKD阶段的加重而升高，并且与氮质血症及尿液浓缩能力下降相关。随着CKD阶段的推进，观察到尿比重（USG）逐渐下降，这与以往研究结果一致，即CKD进展与因肾单位丢失导致的肾脏浓缩能力受损相关[25,26]。然而，在CKD第3期和第4期之间，USG未检出显著差异（p = 0.944）。这一观察结果表明，到第3期时肾单位丢失可能已达到关键阈值，导致浓缩能力下降，而随着CKD进展到第4期，进一步下降幅度较小。

血清fPL浓度显示与传统的肾脏生物标志物呈正相关，包括血尿素氮（BUN）、肌酐和无机磷（IP），这些指标都反映了肾小球滤过功能受损和全身性氮质血症。这些关联表明肾功能下降可能会影响fPL浓度的测量。猫胰腺炎的诊断本质上仍具有挑战性，仅凭fPL浓度升高通常不足以确立临床显著的胰腺炎。因此，适当的解读需要结合临床症状和胰腺超声检查结果。此外，已知当肾小球滤过率（GFR）下降时，胰腺酶会升高，这可能是由于肾清除减少，这进一步增加了在患有慢性肾病（CKD）猫中解读fPL结果的复杂性。

在一项对诱导慢性肾病（CKD）猫进行的相关实验研究中，报告显示血清猫胰蛋白酶样免疫反应性随CKD显著升高，而血清fPL与健康对照组相比没有显著差异，并保持在参考范围内。这表明某些胰腺生物标志物可能会受到肾功能障碍的不同程度影响，并强调在氮质血症情况下需谨慎解读fPL结果[27]。在人体医学中，终末期肾病（ESRD）与急性胰腺炎（AP）之间的关联已有充分文献记录，并归因于多种机制。首先，高钙血症被认为是晚期CKD中AP的主要原因，无论是否接受透析。流行病学数据显示，未进行透析的CKD 5期患者和正在接受透析的患者分别发生高钙血症引发AP的可能性增加了4.59倍和1.65倍（p < 0.01）[19,20]。

其次，肾脏在胃肠激素如胆囊收缩素的降解中起关键作用；清除功能受损可能导致持续的胰腺刺激并增加急性胰腺炎的风险。第三，血液透析期间低血压与肠系膜缺血有关，而肠系膜缺血是已知的急性胰腺炎诱因，研究将低血压、高超滤率和升高的胰腺酶浓度联系起来[21]。最后，腹膜透析（PD）可通过高甘油三酯血症、局部高钙血症、腹内压升高以及PD相关腹膜炎等机制增加胰腺炎的风险[22,23,28,29,30,31,32,33,34]。

综合来看，我们的研究结果最符合血清fPL浓度因肾功能下降而被动（非炎症性）升高的情况。在缺乏标准化临床体征评估和胰腺影像学检查结果的情况下，仅凭fPL升高在诊断慢性肾病（CKD）猫的胰腺炎方面存在固有的局限性。在这种情况下，我们的研究为临床医生提供了实际的解读信息。具体来说，当在慢性肾病（CKD）猫中观察到轻度至中度的fPL升高时，这些发现不应单独解读，而应结合相应的临床体征进行评估，并在可行的情况下参考以胰腺为重点的检查。本研究存在一些局限性。首先，缺乏胰腺或肾脏病变的组织病理学确认，这使得无法对潜在疾病做出明确诊断。其次，胰腺超声学检查结果和符合胰腺炎的标准化临床体征未被一致记录，因此无法使用统一的诊断标准来界定胰腺炎。

第三，呈现时的水合状态没有得到一致或客观的量化，尿比重（USG）和一些实验室指标可能受此因素影响。最后，回顾性横断面设计以及纳入同日检测的猫可能引入选择偏倚，并限制了对时间关系的评估。总之，血清fPL浓度与猫的CKD严重程度及肾脏生物标志物相关。这些结果表明，肾功能下降可能导致更高的测量fPL浓度，并强调在CKD猫中不应单独使用fPL来诊断临床显著的胰腺炎。
