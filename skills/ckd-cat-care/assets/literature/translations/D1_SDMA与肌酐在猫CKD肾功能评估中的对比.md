## 慢性肾病（CKD）猫的生物标志物

对称二甲基精氨酸（SDMA）已被证明是计算人体估算肾小球滤过率（GFR）的准确且精确的生物标志物，同时也是比血清肌酐浓度（sCr）更敏感的评估肾功能障碍的生物标志物。本回顾性研究的目的是报告在猫体内测量血清SDMA浓度用于在通过常规sCr测量诊断之前检测慢性肾病（CKD）的实用性。慢性肾病（CKD）猫（n = 21）包括持续氮质血症≥3个月的猫（n = 15）、非氮质血症但GFR比正常猫的中位数GFR下降>30%的猫（n = 4），以及非氮质血症但患有草酸钙肾结石的猫（n = 2）。健康老年猫（n = 21）选自同一群体。

对氨基二甲基精氨酸（液相色谱-质谱法）和血肌酐（酶促比色法）的浓度进行了回顾性测定，来源于历史数据或库藏血清样本，用于氮质血症猫，或在非氮质血症猫进行肾小球滤过率（GFR）（GFR，伊诺索尔清除法）测定时进行检测。血清对称性二甲基精氨酸（SDMA，r =−0.79）和血肌酐（sCr，r =−0.77）浓度与GFR显著相关（均 P < 0.0001）。在21只猫中，有17只猫（平均17.0个月；范围1.5–48个月）对称性二甲基精氨酸升高发生在血肌酐升高之前。血清SDMA的敏感性更高（100%），相比血肌酐（17%），但特异性较低（91% 对 100%），阳性预测值略低（86% 对 100%）。

## 结论及临床重要性

对称性二甲基精氨酸（SDMA）已被证明是计算人类估计肾小球滤过率（GFR）的准确且精确的生物标志物，并且作为评估肾功能障碍的生物标志物比血清肌酐（sCr）更敏感。一项涉及18项人类患者研究的荟萃分析显示，1/SDMA浓度与肌酐清除率高度相关（r =0.85），而SDMA浓度与血清肌酐浓度高度相关（r =0.75）。在另一项使用人类受试者的研究中，通过碘噻唑酸清除法测量的GFR与sCr和SDMA密切相关（r =−0.84和−0.89）。血浆SDMA浓度也被发现在人类慢性肾病（CKD）猫中升高，并与血浆肌酐浓度相关（r =0.74）。简而言之，SDMA是蛋白质甲基化的副产物。主要有三种甲基化精氨酸：单甲基精氨酸（MMA）、不对称二甲基精氨酸（SDMA）（ADMA）和SDMA。随后的甲基化蛋白降解产生个体的甲基化精氨酸氨基酸。

## 动物和研究设计

所有研究方案均已由堪萨斯州托皮卡希尔宠物营养公司（Hill's Pet Nutrition, Inc.）的机构动物护理与使用委员会审核并批准。每只猫每年进行一次体格检查、全血细胞计数（CBC）、血清生化分析、尿液分析，以及在尿液分析结果显示需要时进行尿液培养。此外，2010年之后，血清样本会在−70°C冻结保存，以备回顾性分析使用。猫被单独或群居饲养，并允许在室内通道中进行运动。猫可以接触到随季节变化的自然光。所有猫定期有机会运动，并且可使用玩具。所有猫均由本研究的商业资助者或其附属机构拥有，并获得许可参与本研究。

所有猫在历史上都曾用于适口性研究。喂养了多种不同类型的商业和非商业食品，这些食品营养成分各异，包括干猫粮和罐装猫粮。所有食品均符合美国饲料控制官员协会（AAFCO）为成年猫制定的完整均衡宠物食品要求。患有慢性肾脏疾病（CKD）的猫（n = 21）来自一个有超过400只家短毛猫的群体。群体中的猫龄从1岁到19岁不等（平均7岁），约25%的猫年龄超过10岁。患有CKD的猫（n = 21）包括那些在较长时间内持续氮质血症的猫，通常≥3个月（n = 15）。在非氮质血症猫（血肌酐浓度稳定）中，通过碘克沙醇清除法进行肾小球滤过率（GFR）检测确诊CKD（n = 4）。非氮质血症且有草酸钙肾结石的猫也被认为患有CKD（n = 2）。

患有慢性肾病（CKD）的猫未显示其他混杂疾病的证据，尽管其病史和体格检查结果（尿量变化或肾脏大小或形状的变化）与CKD一致。CKD猫的平均年龄为14.3岁（范围8.0–18.5岁）。其中有15只已绝育的雌猫和6只已去势的雄猫。平均体重为4.0公斤（范围2.6–5.7公斤）。一些患有CKD的猫可能存在未被诊断的急性肾病。例如，由于尿液沉渣检查结果正常并不能明确排除感染，尤其是在CKD猫中，潜在的肾盂肾炎可能未被诊断。在患有慢性泌尿结石的猫中，结石可能移动，导致部分输尿管梗阻和急性肾损伤。

从同一个群体中选择了类似数量的健康老年猫（n = 21）。纳入标准为年龄大于10岁，需要在6个月内进行3次正常的肾小球滤过率（GFR）测试、3次正常的血肌酐（sCr）浓度测定，以及3次尿比重（USG）测定值大于1.040。此外，这些猫在纳入时没有历史或体格上显示的混杂疾病的证据，并且有银行储存的血清样本可用于测定SDMA浓度。健康老年猫的平均年龄为11.7岁（范围为10.2–13.1岁）。其中有12只接受过卵巢子宫切除术的雌性猫和9只已绝育的雄性猫。平均体重为4.5公斤（范围为3.1–6.3公斤）。

回顾性数据用于记录慢性肾病（CKD）猫的血清肌酐（sCr）浓度。血清对称二甲基精氨酸（SDMA）浓度是从血清库中储存的血清中测定的。血清肌酐（sCr）和对称二甲基精氨酸（SDMA）浓度也通过前瞻性收集的慢性肾病（CKD）猫的血液进行测量。

## 肾小球滤过率（GFR）

血清中伊奥昔醇的浓度由商业实验室使用感应耦合等离子体原子发射光谱法（ICP-AES）测定。简要来说，给予一次静脉注射伊奥昔醇（一种碘化造影剂，300 mg I/kg），并在注射后2、3和4小时分别采集3个血清样本。肾小球滤过率（GFR）通过使用血清伊奥昔醇清除的一室模型计算得出。本研究中健康正常猫的中位数（范围）GFR，通过每只猫在6个月期间进行3次伊奥昔醇清除测试测定，为1.94 mL/min/kg（范围：1.34–3.79 mL/min/kg）。

考虑中的慢性肾病（CKD）猫为IRIS 1期（血肌酐 sCr < 1.6 mg/dL）或2期（血肌酐 sCr 1.6–2.8 mg/dL），且在诊断时为非蛋白尿（尿蛋白/肌酐比 UPC ≤ 0.2）或边缘蛋白尿（UPC 0.2–0.4）。所有健康老年猫的血清SDMA和血肌酐浓度均在正常参考范围内。因此，血清SDMA是早期检测肾功能受损猫CKD的有前景的生物标志物。早期检测是可取的，因为这可能有助于更早地开始饮食或其他干预措施，以减缓CKD的进展，正如对IRIS 2期和3期CKD猫所显示的那样。血清SDMA和血肌酐浓度之间存在显著正相关（r = 0.72），这一结果与此前报道的CKD猫的情况类似。这些结果支持SDMA主要通过肾脏排泄。此外，我们的证据表明，非氮质血症猫若SDMA浓度 >14 μg/dL，最终会发展为氮质血症CKD。

血清SDMA是一种相对较新的生物标志物，可用于在无氮质血症猫群中早期检测慢性肾病（CKD）。在所有肾小球滤过率（GFR）<1.36 mL/min/kg（健康猫的中位数为1.94 mL/min/kg）的无氮质血症猫中，血清SDMA浓度均>14 μg/dL。我们选择GFR<1.36 mL/min/kg（比健康猫中位数下降30%）作为符合CKD诊断的标准，这是基于健康老年猫GFR测量值的下2.5百分位为1.36 mL/min/kg。SDMA的正常参考区间<14 μg/dL对应的GFR为1.47 mL/min/kg（大约比中位数下降24%）。因此，2只患有CKD的猫SDMA浓度≥14 μg/dL，但通过碘酮葡萄糖清除法测量的GFR未低于1.36 mL/min/kg。因此，SDMA浓度显示这2只猫的GFR降低为假阳性。两只猫的GFR为1.45 mL/min/kg（比中位数GFR下降25%）。我们用于CKD诊断的截止值（<1.36 mL/min/kg）降低了SDMA检测的敏感性至91%。

血清 SDMA 是核内蛋白甲基化的副产物。虽然磷酸化是最为人所知的蛋白质翻译后修饰，但精氨酸甲基化也很重要。精氨酸甲基化发生在多肽链中精氨酸的氮原子在翻译后被修饰以含有甲基。主要有三种甲基化精氨酸的类型：MMA、ADMA 和 SDMA。甲基基团通过几种蛋白精氨酸甲基转移酶（PRMT）之一从 S-腺苷甲硫氨酸转移到精氨酸的氮上。随后，通过水解降解甲基化蛋白质会产生单个甲基化精氨酸氨基酸，这些氨基酸具有生物活性。ADMA 作为内源性一氧化氮合酶（NOS）抑制剂，可阻止 L-精氨酸生成一氧化氮。

虽然SDMA不是一氧化氮合酶（NOS）的直接抑制剂，但它可以与精氨酸竞争穿膜运输，因此通过限制l-精氨酸的供应间接降低一氧化氮的合成。不对称二甲基精氨酸（SDMA）主要在二甲基精氨酸二甲基氨基水解酶（DDAH）代谢后降解为二甲胺和瓜氨酸（≥80%），而通过肾脏排出的完整ADMA仅占少量（≤20%）。对称二甲基精氨酸（SDMA）主要（≥90%）通过肾清除排出。尿液中二甲基精氨酸的存在已被确认超过40年。由于SDMA通过肾脏排泄，血浆浓度会受到肾小球滤过率（GFR）变化的影响。

不对称二甲基精氨酸（SDMA）在肾功能障碍患者中会积累，尽管它的含量低于SDMA，其积累可能与肾实质损伤有关，导致DDAH表达和活性下降，而不是与ADMA肾小球滤过减少有关。在来自Framingham后代队列的健康人群中，膳食成分与血浆SDMA浓度无关。对称二甲基精氨酸（SDMA）浓度与年龄和血清肌酐浓度呈正相关，而体重指数、有效肾小球滤过率（GFR）和舒张压与SDMA浓度呈负相关。肾小球滤过率（GFR）与功能性肾组织量直接相关。

早期检测肾小球滤过率（GFR）下降可能对应对慢性肾病（CKD）猫咪在血清肌酐（sCr）浓度仍在正常参考范围内（≤2.1 mg/dL）时采取饮食或药物干预非常重要。然而，由于GFR测量困难、费用高昂且需要多次采血或24小时尿液收集，GFR检测仍然是诊断和管理肾脏疾病中未被充分利用的工具。相反，通常使用连续的血清肌酐浓度来评估肾功能，因为血清肌酐易于测量且费用较低。但是，IRIS 1期和2期CKD猫咪的血清肌酐可能是正常的，因为直到大约75%的肾单位失去功能后，血清肌酐才会超过参考范围。使用血清肌酐作为CKD生物标志物的其他局限性包括某些类型检测中血清肌酐浓度可能升高，以及雄性犬的肾小管中血清肌酐分泌增加。

因为肌酐是肌肉中磷酸肌酸的非酶促分解产物，体内每日肌酐的产生主要由肌肉质量决定，因此总体瘦体重也可能影响血清肌酐浓度。总体而言，它作为慢性肾病（CKD）的早期生物标志物并不理想。犬和猫的正常肾小球滤过率（GFR）定义不明确，因此建议使用检测注射GFR标记物的实验室建立的参考范围。这有助于因方案差异而产生的宽参考范围。用于测量GFR的标记物应能够自由通过肾小球滤过，不与血浆蛋白结合，也不被肾小管再吸收或分泌，无毒性，并且自身不能改变GFR。胰果糖被认为是测量GFR的金标准。然而，在猫中，使用2–4个血浆样本测定依昔罗昔嗪的血浆清除率可以准确估算GFR。通过使用依昔罗昔嗪血浆清除率来估算健康猫的GFR，我们随后选择了下方2.5百分位作为正常GFR的下限。

血清SDMA浓度与GFR呈反比关系（r =−0.79），随着GFR的下降而在猫体内升高。由于SDMA被认为仅通过肾脏排泄，因此SDMA已被提议作为人类肾功能的标志。最近，有研究报告称，在人类志愿者中，二甲基精氨酸可提供GFR的准确且精确的估计，并且可作为比血清肌酐更敏感的肾功能障碍生物标志物。在假设已经排除了肾前性（容量反应性）GFR下降原因及急性肾损伤原因的情况下，血清SDMA浓度升高（阳性测试）作为单点测量或筛查测试，对于确认慢性肾病（CKD）具有中等效果（阳性预测值PPV = 86%），尽管仍需进一步监测。然而，SDMA升高正确识别了所有阳性慢性肾病（CKD）病例（100%敏感性；也称为真阳性率，即真阳性数除以真阳性与假阴性之和的比值）。

作为筛查测试，阴性结果对于让主人放心患者没有慢性肾病（CKD）非常有效（阴性预测值 NPV = 100%），但初步筛查测试仅能正确识别91%没有CKD的猫（特异性 91%；也称为真正阴性率，即真正阴性除以假阳性加真正阴性的比值）。相比之下，使用血肌酐（sCr）作为筛查测试时，血肌酐升高（阳性测试）对于确认CKD非常有效（阳性预测值 PPV = 100%）。然而，它只能正确识别17%的所有病例（敏感性）。这与其他人的结论一致，即血浆肌酐对于猫早期肾功能障碍的诊断敏感性不足。作为筛查测试，阴性结果对于让主人放心患者没有CKD效果不佳（NPV = 70%），尽管在初步筛查中测试能够正确识别100%没有CKD的个体（特异性）。

由于使用为患有慢性肾病（CKD）的猫设计的适当配方肾脏饮食进行营养干预相对安全，因此可以认为，基于使用 SDMA 作为生物标志物来治疗猫的慢性肾病（CKD），因为其敏感性更高，比依赖肌酐（sCr）这一对慢性肾病（CKD）具有更高特异性的指标而错过慢性肾病（CKD）猫，更为合理。

人们对寻找新的生物标志物以追踪猫的肾病进展（例如SDMA、ADMA和成纤维细胞生长因子（FGF-23）23）12、23、24以及狗（如同型半胱氨酸、半抑素C和簇素）有相当大的兴趣。25,26 由于血浆中SDMA和ADMA浓度在患有慢性肾病（CKD）的猫中被证明会增加，并且与血浆Cr相关， 它们被建议作为肾病的可能标志物，尽管在猫中未研究与GFR的相关性。12 在人类中，慢性肾病（CKD）患者中SDMA比ADMA更为丰富，且ADMA浓度与GFR的相关性明显低于SDMA与GFR之间的相关性。14 猫中成纤维细胞生长因子（FGF-23）23的浓度与GFR呈负相关（r = −0.472），并在CKD早期非中极性阶段有所增加。24 然而， 与人类类似，当GFR显著下降时，独立因素如磷酸盐、甲状旁腺激素（PTH）和钙浓度可能是血浆成纤维细胞生长因子（FGF-23）23浓度的更重要预测因素。23,27 给IRIS CKD第2期及以上的猫咪喂养肾脏饮食被视为当前的标准护理，且具有强力
