重要声明：本表由猫家长社群共同整理，属于经验型清单，不是处方。原表已明确「对用药结果一概不负责，各位家长遵医嘱」。本清单在此基础上补充了证据等级与风险提示（黄色区块为整理者补充，非原表内容）。任何药物开始、加量、联用前，请与你的主治兽医确认，尤其是注射剂、促红素、降压药与骨化三醇。

四个用法要点：
  • 先分期、再选药：原表标注了「建议使用分期」，1–2 期与 4 期的用药重点完全不同。
  • 随餐 / 空腹决定了有没有效：磷结合剂必须餐中吃，硫糖铝必须空腹，这两个搞反了等于白吃。
  • 叠加前先查间隔：活性炭、磷结合剂、硫糖铝都会「吸附」其他药，见「服药时机与冲突」。
  • 黄色区块是整理者补充：包含循证提示与风险提醒，帮助你判断「这个药到底值不值得上」。

B 常规用药（有临床共识）骨化三醇 / 丰兹欧 / 鱼油（三选一组合） ⚠

建议分期
CKD 1–4
给药方式
口服
猫用量
1. 骨化三醇用量：询问（按体重与离子钙）
2. 丰兹欧：1 粒/天
3. 鱼油（EPA）：4kg 以下 120mg/天；5kg 180mg/天；6kg 以上 300mg/天
狗用量
骨化三醇暂无参考；7kg 以上大狗若用骨化三醇可叠加鱼油（EPA 摄入量无数据）

  • 2. 体重大（＞7kg）且离子钙正常：骨化三醇 + 鱼油
  • 3. 离子钙高、折耳猫、高血钙、肾结石：只用普通鱼油
  • 4. 骨化三醇分装需用肠溶胶囊，分装方法咨询群
  • 5. 用骨化三醇/丰兹欧期间：其他含钙补剂和药要停
  • 与骨化三醇同服需谨慎：含钙磷结合剂、巴比妥类、皮质类固醇、含镁抗酸剂、噻嗪利尿剂
整理者补充：骨化三醇是活性维 D，用前必查「离子钙 + 总钙 + 磷」，用药后 1–2 周复查；钙磷乘积过高会加速肾与软组织钙化，绝不能凭感觉加量。

⑤ 风险红榜（整理者补充）

⚠ 奇亚籽「降钙」

奇亚籽磷含量高（约 800–900 mg/100g），对需要控磷的肾猫是帮倒忙。

⚠ 3% 双氧水涂口腔

灼伤黏膜、误吞致呕吐/食道炎，家庭环境不建议常规使用。

⚠ 长期含铝磷结合剂

铝蓄积可致神经症状、小细胞性贫血，尽量短期低剂量。

⚠ 盲目补铁

不查铁状态就长期口服铁，会便秘、干扰其它药吸收、加重氧化损伤。

⚠ 骨化三醇不看离子钙

高钙会加速肾脏与软组织钙化，是「越补越坏」的典型。

⚠ 活性炭当主力降氮

非选择性吸附，会把所有同服药物吸走，还加重便秘与脱水。

⚠ EPO 替代 DPO

人用 EPO 免疫原性高，可能诱发抗体导致纯红再障（PRCA）。

⚠ 自行叠加降压药

替米沙坦 + 贝那普利联用会放大高钾与肾灌注下降风险，必须监测。替米沙坦与氨氯地平联用时必须从 ≤1 mg/kg q24h 起（防低血压）。

⚠ 脱水或 CKD 不稳定时上 RAAS 抑制剂

指南明确 ARB / ACEI 仅用于未脱水且病情稳定的猫，否则可能加重肾灌注不足。

⑥ 按 IRIS 分期的用药阶梯

IRIS 1–2 期

血压与蛋白尿是主线：UPC>0.4 考虑替米沙坦 2 mg/kg q24h；血压>160 上氨氯地平 0.125–0.25 mg/kg q24h（目标理想 <140、否则 <160）；低磷饮食起步；补充剂（胺肾/鱼油/益生菌）可选。

IRIS 3 期

加入降磷（碳酸镧维福瑞随餐）；监测贫血与血钾；BUN 高可考虑益生菌/吸附剂；开始考虑皮下补液（剂量见《照护手册》4.3/4.4）。

IRIS 4 期

通常需规律皮下补液；止吐（赛瑞宁）+ 护胃（奥美拉唑/硫糖铝）+ 促食欲（米氮平）组合；严重贫血评估 DPO；考虑喂食管。
说明：分期依据 IRIS 2026（肌酐 / SDMA + UPC + 血压）。本工作区已有《猫慢性肾病新手家长照护手册》与 33 篇文献译文，分期标准、补液剂量、无机磷规避等细节可对照查阅。
